# 女主人物设定｜谢珊珊

> 用途：动漫化视觉基准（非露骨）  
> 参考文本：《谢珊珊·五日》

---

## 一、基础信息

| 项目 | 设定 |
|------|------|
| 姓名 | 谢珊珊 |
| 称呼 | 晓晓叫「珊珊」；男主被她称为「阿凯哥」 |
| 年龄感 | 二十出头至中段，学生气刚褪尽的青年女性 |
| 身份 | 外地来沪散心的闺蜜；有男友阿杰，关系紧张 |
| 身高感 | 偏高，腿长是第一视觉记忆点 |
| 体态 | 腰细、肩窄、胸臀有柔和曲线；皮肤偏白 |

---

## 二、外貌关键词（动漫化）

1. **腿**：干净、修长，站姿与走路时的线条优先于脸部特写。
2. **脸**：柔和鹅蛋脸，杏仁眼，睫毛长，目光易「亮一下」也易躲闪。
3. **发**：及肩偏长的直发，湿发贴颊是关键识别状态。
4. **锁骨 / 颈侧**：侧面构图常用，表达脆弱与距离感。
5. **手**：细、凉；递物、抓裙摆、捂嘴等小动作戏份多。
6. **耳尖**：紧张时易红——情绪可视化的小机关。

---

## 三、气质与表演轴

- **表层**：甜、礼貌、旅途疲惫后的软声线。
- **中层**：不安、自我怀疑、习惯把事往「我想多了」里圆。
- **深层**：会忍、会藏、崩溃也尽量无声——「忍」是角色核心戏剧张力。

表情三态（设定图已示意）：

1. 礼貌笑（接机、对晓晓）
2. 警惕侧视（察觉越界）
3. 疲惫空洞（后期伪装平静）

---

## 四、服装系统（分场识别）

| 场次 | 服装 | 视觉功能 |
|------|------|----------|
| 虹桥接机 | 浅色连衣裙，领口克制、腰收紧 | 第一印象：清爽、曲线被布料「说清楚」但不露骨 |
| 居家 | 宽松 T 恤 + 短裤，湿发 | 放松感与不安全感并存 |
| 影院 / 裙底机位场 | **JK 短裙套装**（见下） | 短裙提供机位叙事空间；坐姿并膝可演「夹紧 / 躲闪」 |
| 迪士尼 | **紧身牛仔裤 + 浅色上衣**（见下） | 长腿线条清晰；人群贴靠戏不靠露腿，靠体距与反应 |
| KTV / 饯行 | 裙装，淡妆遮青黑 | 「还能维持体面」的最后外壳 |

原则：服装服务人物状态，不靠暴露推动叙事；尺度段落用**机位、景深、遮挡物、剪影**处理。

### 4.1 JK 短裙（影院 / 裙底机位）

- **组成**：白底水手领上衣 + 深蓝领结/飘带 + 深蓝百褶短裙 + 深色中筒袜 + 乐福鞋；可加浅色开衫
- **识别点**：百褶裙摆摆动、坐姿并膝、双手按住裙角
- **分镜用途**
  - 裙底机位：只拍到裙摆内侧阴影切断 / 桌沿遮挡 / 过肩俯角，**不直出内衣全貌**
  - 影院摸腿：黑暗中手部局部 + 她夹腿、咬唇、侧脸泪光；银幕反光打在膝盖
- 设定图：`xie-shanshan-outfit-jk-skirt.png`

### 4.2 紧身牛仔裤（迪士尼）

- **组成**：修身浅色无袖/短袖上衣 + 深蓝紧身牛仔裤 + 白运动鞋 + 小斜挎包；可选遮阳帽
- **识别点**：腿长被牛仔裤「画」出来；背面/侧面剪影干净
- **分镜用途**：排队贴靠、安全带戏用腰侧与表情，不靠短裙走光
- 设定图：`xie-shanshan-outfit-jeans-disney.png`

---

## 五、色彩与线条

- **主色**：米白、浅杏、淡粉灰（衣）+ 暖褐发色
- **肤色**：瓷白，阴影用冷灰紫，避免油腻高光
- **线稿**：细而稳，腿部与颈侧线条干净
- **画风倾向**：偏写实比例的青年向 TV 动画人设，非 Q 版、非重度性感动效

---

## 六、镜头遮挡约定（为后续分镜预留）

露骨内容不直接画全：优先用门框、被子边缘、桌沿、镜面反光、过肩特写、手部局部、光影切断等方式「说到为止」。女主完整性体现在**表情、呼吸、手的拒绝/卸力**，而非身体展览。
