# 独立构思四题

人物、地点、机制各自独立，互不串场。  
视角：男主第一人称。尺度：全露骨。角色均默认 24 岁以上。  
只写大纲，不写正文。

---

# 一｜《卫晚棠·呼吸》

困住她的不是房间，是水深。丈夫在船上，只能听见她的呼吸。

## 人物

| 角色 | 设定 |
|---|---|
| **靳承野** | 男主。34 岁。潜水教练。话少，水面以上像可靠的人，水下没有表情。 |
| **卫晚棠** | 女主。28 岁。第一次考开放水域。腿长，防晒衣拉链习惯拉到锁骨下一点。怕给别人添乱，指令一来就执行。叫他「靳教练」。 |
| **裴溯** | 晚棠丈夫。留在船上当水面支持：盯浮标、听对讲、记时间。他听得见呼吸声，看不见水下的手。 |

- 地点：海南陵水外海。船小，其他学员第一天已上岸。只剩补考的她、教练、当志愿者的丈夫。  
- 时间：海上一日，加岸上民宿一夜。  
- 把柄：水下相机。画面里是标准教学姿势，只有放大才能看见手指的位置。她若声张，像污蔑教练；他若放出放大版，则是她自己的身体。

## 机制

对讲里裴溯会问：「还好吗？」她必须说「好」。说不好，丈夫会让她上浮，教练就有理由在水下「检查装备」拖时间。呼吸声一乱，船上的人全知道——所以她只能把乱掉的呼吸练成平稳的泡。

## 章法（五章）

**第一章｜下潜**  
教平潜。他从后面纠正腰，掌心贴小腹，说「沉下去」。水面裴溯挥手。她以为这是教学。

**第二章｜面镜**  
教排气。他捧着她的面镜，鼻尖相距不到一拳。气泡打在他下巴。水下他拉开她防晒衣拉链「检查配重」，手停在胸下沿。她想上浮，他按住BCD，比了一个「慢」。对讲里丈夫问还好吗。她按通话：「好。」气泡成串。

**第三章｜平台**  
五米平台停留。能见度差，船影在头顶。尺度：手套仍戴着，隔着潜水裤按到缝。她呼吸陡然变响。船上裴溯的声音发紧：「棠棠，你在换气吗？」靳承野把通话器按给她。她必须说：「练习。别担心。」手还在那里。

**第四章｜夜潜（完成式）**  
补一项夜潜。灯只照前方。他在她身后进入——潜水服只解开必要的部分，海水又冷又涩，动作只能小。完成式是呼吸：每一下顶弄都变成对讲里的「呼——吸」。裴溯听见的是教科书般稳定的节奏，因为她拼命把喘压成训练。内射在水里散开，看不见。上浮前他把相机红灯关掉。

**第五章｜上岸**  
甲板上裴溯给她围毛巾，夸「呼吸比早上稳多了」。教练递结业照：两个人在水下并排，姿势正规。原片他留下。民宿夜里她不敢洗澡太久，丈夫问「是不是水太冷」。她说冷。

收束：对讲机还在充电。她听见自己白天的那句「好」。

# 二｜《季南枝·不要破戏》

困住她的是观众。台下第三排坐着她的未婚夫。场灯一亮，所有触碰都叫表演。

## 人物

| 角色 | 设定 |
|---|---|
| **牟临** | 男主。31 岁。沉浸剧男主兼现场导演。有权改走位、加互动、延长某一幕。 |
| **季南枝** | 女主。26 岁。临演顶上的女主。第一次扛整场。怕破戏被圈内封杀，更怕未婚夫看见自己「演砸」。 |
| **方朗** | 南枝的未婚夫。被她请来说「来看我第一场」。坐第三排，会录像（场馆允许无闪光）。 |

- 地点：旧仓库改建的沉浸剧场。多房间，观众可跟随。有一间「镜屋」对外只开一条观察缝。  
- 时间：连演三场，三夜。  
- 把柄：官方机位 + 方朗手机里的「我女朋友好拼」。正片是艺术，私存的缝是另一回事。

## 机制

剧本里本就有强制、禁声、跪。观众越鼓掌，牟临越敢加码。她若当众喊停，这场戏黄，票款、剧团、未婚夫的脸，一起碎。他在耳麦里只说一句：「别破戏。」

## 章法（五章）

**第一章｜走位**  
彩排。他教她被按在墙上时怎么侧脸对光。手已经超剧本两寸。她忍了。方朗在门外等，还没入场。

**第二章｜第一场**  
观众进。第三排那张脸让她腿软。规定动作：被捂嘴、被抵在桌沿。牟临在掌声里把膝盖顶进她两腿之间，力度不是彩排。耳麦：「看他。笑。」她对着未婚夫的方向笑。方朗竖大拇指。

**第三章｜镜屋**  
第二夜，他加一场「只对少量观众开放」。观察缝外有人呼吸。尺度：口。她必须把声音做成角色的哭腔。缝外有人低声说「这段真敢」。她认不出那人是不是方朗。射在嘴里。她咽，因为吐出会坏妆，下一幕立刻接。

**第四章｜第三夜（完成式）**  
终场。他改结局：不在舞台中央，在镜屋关缝。只留一条缝给「幸运观众」。他让检票把方朗领到这条缝——未婚夫以为是特权。缝内进入。南枝看见缝外那只眼睛。她不能喊未婚夫的名字。完成式是她把高潮压成一句剧本里的「我认」。内射。缝外方朗事后说：「你哭得好真。」

**第五章｜谢幕**  
三个人吃饭。方朗敬牟临：「把她逼出状态了。」牟临碰杯。桌下南枝的腿还在抖。微信发来一段官方花絮，刚好剪掉真正发生的部分，留下她的侧脸和那句「我认」。

收束：剧评写「第四面墙被推倒」。她知道倒向哪一边。

# 三｜《沈拾花·回潮》

困住她的是时间表。潮水按分钟涨。岸上的丈夫喊得见她，走不过来。

## 人物

| 角色 | 设定 |
|---|---|
| **江咎** | 男主。33 岁。潮间带向导。熟悉哪一块礁石会先成岛。把路线走成计谋。 |
| **沈拾花** | 女主。25 岁。来写生。裤脚卷到膝，皮肤被盐风吹得干。叫他「江老师」。 |
| **沈父乾** | 拾花的丈夫，姓沈，从夫姓的玩笑她从不喜欢，对外仍叫他「乾哥」。本想一起赶海，膝伤留在栈桥上。他能看见那块礁，能喊，不能涉过去。 |

- 地点：浙东一处未开发潮滩。回头潮来得比预报快。礁上有半废的避潮棚。  
- 时间：一个午后到次日退潮。一夜。  
- 把柄：她写生用的相机。岸上乾哥也在拍「风景里的她」。两台机器拍同一块礁，内容不同。

## 机制

回潮把礁做成孤岛。救援要等退潮。乾哥在栈桥喊「花！别怕！我叫人了！」声音清楚。棚壁是一层铁皮。她一叫，丈夫听得见内容；她不叫，丈夫只听见海。江咎让她选：让他听见什么。

## 章法（六章）

**第一章｜预报**  
出发前江咎看表，说「回得早」。他把她带去更远的礁「构图更好」。乾哥在栈桥架相机，挥手。

**第二章｜水线**  
水过踝、过膝。她要往回走。他说「现在走会被带倒，棚里等」。第一次触碰发生在把她拽上礁的时候，手在胸下，像救。

**第三章｜喊话**  
乾哥喊她名字。她要应。江咎站在她身后，手已经进外套。气声：「应完再喘。」她对着海喊：「我没事——」后半截被揉碎。栈桥上乾哥比了个「加油」的手势。

**第四章｜棚**  
铁皮棚。尺度：口、手。海声极大。她把声压进喉咙。江咎偏在她应丈夫的间隙顶深一点，让那声「嗯」像哭腔。乾哥问：「你是不是冷？」她说：「冷。」

**第五章｜夜（完成式）**  
灯塔扫过一次。完成式是她必须自己把手电晃三下——约定的「还活着」信号——同时被进入。内射。潮声盖过一切。她把信号晃稳。岸上乾哥回了三下。两口人隔水报平安，礁上的事被算进风里。

**第六章｜退潮**  
清晨能走了。乾哥涉到膝来接，把外套给她。问江咎：「辛苦，昨晚她有没有吓到。」江咎说：「她很安静。」拾花手里的写生本被海水泡皱，相机里有几张对焦失败的暗部。江咎要走那些「废片」帮她清。她给了。

收束：栈桥木板还湿。乾哥说下次不让她走那么远。她看着水线，知道远近不是自己选的。

# 四｜《容知微·备降》

困住她的是一张房卡。飞机备降，航空公司只剩一间房。丈夫在另一个机场等一个不会降落的航班。

## 人物

| 角色 | 设定 |
|---|---|
| **韩析** | 男主。30 岁。邻座。西装皱了，像出差的人。话不多，帮她拿过一次呕吐袋，从而取得「不是坏人」的第一印象。 |
| **容知微** | 女主。27 岁。晕机。婚戒很新。原定去会合丈夫的周年旅行。叫他「韩先生」，后来只会叫「你把门……」。 |
| **容知微的丈夫·安择** | 人在目的地机场。航班取消后改签更晚。整夜视频、定位、问「房型怎么样」。他看不见那间房只有一张床。 |

- 地点：北方三线机场旁的航空协议酒店。隔音差，走廊有同样被备降的旅客。  
- 时间：落地十八点到次日午后复飞。一夜。  
- 把柄：她为了向安择证明「安全」，自己打开的视频。画面是天花板和她的脸。镜头下沿是不该出现的肩。

## 机制

航空公司书面安排：异性也须拼房，否则露宿航站楼。她若拒绝韩析，要自己承担「不配合安置」。安择在电话里说：「有人陪着我放心，你别一个人。」这句话把陌生人变成丈夫授权的同伴。

## 章法（六章）

**第一章｜颠簸**  
开篇在气流里。她抓扶手，抓到他的袖。落地。广播备降。

**第二章｜一间**  
柜台。最后一间大床。她想改，没有了。安择电话：「别折腾了，你先睡，我明天接你。」韩析把房卡递给她：「你先进。」

**第三章｜视频**  
她给安择看房间：窗、壶、那张床。韩析站在镜头外。挂断后他说：「他还要你报平安。那就别吵。」第一轮越界发生在她洗脸的时候——门没插好，他进卫生间，手从后面进她睡衣。她要叫。走廊有人推着行李箱经过。她把水龙头开大。

**第四章｜报平安**  
安择再打来。她必须接。韩析让她把手机靠在台灯，镜头只切脸。尺度：口。她说话时气断：「没……没事，有点晕。」安择说：「那早点睡。」她应「嗯」，嘴里还有人。

**第五章｜床（完成式）**  
只一张床。完成式是她主动把安择的定位共享打开——丈夫要看她「还在酒店」。地图上一个蓝点很安稳。蓝点下面她被进入。内射。她求不要弄到床单，怕早上服务员。他偏弄在里面。「床单干净，你走得了。」

**第六章｜复飞**  
次日机场。安择发来接机牌照片：「我在到达口。」她过安检时腿仍并着。韩析在另一队，像不认识。微信一张天花板的截图，只有她的眼和一截锁骨。没有脸的下半。够她懂。

收束：飞机重新起飞。安全带提示音。她握着婚戒转了一圈。邻座换成别人。

# 怎么选

| 题目 | 把她按住的东西 |
|---|---|
| 《呼吸》 | 水深；丈夫只听见吸气 |
| 《不要破戏》 | 观众；未婚夫在鼓掌 |
| 《回潮》 | 潮汐；岸上喊得见、走不过来 |
| 《备降》 | 一间房；丈夫授权「有人陪着放心」 |

四条都是一夜或三夜，不写长篇日常。若要写正文，先定一条。
