# 大纲五｜《宋映微·软卧》

> 新墙：**一张下铺帘子，和帘外四个活人的呼吸。**  
> 时间盒不是五日旅游，是一趟二十二小时的夜车。

## 一、人物

| 角色 | 设定 |
|---|---|
| **顾疏衡** | 男主。31 岁。广告公司美术指导。表面话少、会让座、会帮行李。已婚。 |
| **宋映微** | 女主。25 岁。出版社编辑。瘦、颈长、戴细金边眼镜，穿衬衫时胸被衣料压得很服帖。怕给别人添麻烦到近乎病态。称男主「疏衡哥」。 |
| **覃可** | 顾疏衡的妻子，宋映微大学学姐。没坐这趟车。是她买的票、选的包厢：中铺对着中铺，「路上有我老公，你睡觉把帘子放下来就行」。全程只在微信里：问到了没、问吃没吃、问我老公烦不烦你。 |
| **厉北** | 宋映微男友。原定同车，临时被单位留下。约定终点站接她。视频会打进来。 |
| **同包厢** | 下铺对门：一对回老家的中年夫妻，打呼噜、吃水果、半夜上厕所。上铺：一个戴耳机的男生，几乎不出声。他们是墙，也是定时炸弹。 |

- 车次：Z字头，硬景软卧。广州 → 郑州。二十二小时。  
- 铺位：顾疏衡下铺，宋映微中铺（覃可特意让她「不用爬太高」）。他一抬头，帘缝里就是她的小腿。  
- 把柄：帘内、睁眼、背景是铺号牌和覃可发给她的「到了报平安」聊天顶栏截在同一张图里。看起来像她同意在学姐丈夫的铺上睡。

## 二、为什么这容器新

- 没有门，只有帘。帘不是锁，是表演：拉上=我们在睡觉；声音大了=全包厢知道。  
- 列车员两小时一巡，会掀帘角查票。  
- 车体摇，合法地把体重压上去。  
- 她若喊，第一句会变成「你在火车上诬陷照顾你的人」，且同包厢都是证人——证人只听见过她叫他「疏衡哥」。

## 三、二十二小时总线

```
上车     行李、让铺、学姐语音   → 第一道缝：扶腰、关门时的贴
晚饭     餐车挤               → 合法的胯
上铺后   她中铺，他抬头        → 看；她察觉，把腿收回去
零点     同包厢睡沉           → 他爬到中铺帘内；摸；她不敢喘
凌晨三时 列车员查票           → 她必须自己应「在」；知情
清晨     洗漱间               → 口；门外有人排队
午后     过隧道               → 黑暗七十秒；清醒进入
到站前   覃可已在出站口       → 夹着东西被妻子拥抱；厉北的电话响了
```

## 四、分章（六章）

### 第一章｜铺号

开篇在站台，不是出站。覃可的语音还在播：「中铺，别跟陌生人换。我老公下铺，有事踩他一下。」宋映微笑着跟他点头，耳根已经红了——她没见过学姐丈夫本人，照片里斯文，现场更高。

行李进包厢。中年女人已经把鞋脱了。他帮映微抬箱子上行李架，她在他身下递锁，胸口擦过他小臂。关门。包厢瞬间变小。

他让她先坐他下铺换鞋。鞋拔了，她的脚在他两膝之间。他低头帮她放鞋，视线顺着小腿进裙摆的阴影。她并腿。他说「站稳」。

章末：发车。覃可消息：到了报平安。他回了「人在我这儿」。映微看着那五个字，说不清为什么心里发紧。

### 第二章｜餐车

过道窄。他跟在她后面，车晃，胯贴上她臀。她回头，他摊手「车」。餐车座位四人桌，对面是陌生人。桌下他的膝顶着她的膝，一直到盒饭吃完。她把腿挪开，车又晃回来。

回包厢。中年男人已经打鼾。她爬中铺，裙子在爬梯上短一截。他站在梯下「保护」，看了完整的一秒钟。她躺下，把帘放到底。他的上铺空着——他睡下铺，却把脸对着她的帘。

夜。他不爬上去。只伸出手，从帘下缘摸到她的脚踝。她弹了一下，没有出声。同包厢的鼾声正好盖住她抽气。他停在小腿。今晚只到这里。让她自己决定要不要把帘压死、要不要换铺。

她没有换。她把帘压死了。压死之后他的手更看不见，也更自由。

### 第三章｜中铺

零点。他轻声说「我上去拿充电器」。梯子响。中铺帘被掀开一条，他挤进去。空间只够侧躺。她的背贴壁，胸贴他。眼镜还戴着，镜片起雾。

「下去。」气声。  
「你一喊，他们对面就醒。你跟覃可怎么说？」

尺度：隔着内裤用手，把她做湿。不进入。她咬枕巾。车过岔道，整节车厢颠一下，他的手指进得更深。她差点叫出来，改成咳嗽。下铺女人含糊问「小姑娘你感冒啊？」她必须应：「……空调。」

他把她的手按到自己裤裆，只按住，不强迫套动。说：「到郑州之前，你想让它安静，就自己管着。」

他爬下去。她的中铺帘再没拉严。

### 第四章｜查票

凌晨三时。列车员敲壁：「查票——」手已经掀他下铺。他不在。列车员抬头，掀中铺。两个人挤在一张铺上，衣服还在，姿势解释不清。

宋映微先开口，声音稳得可怕：「我恐高，下来坐一下。票在这儿。」把身份证递出去。列车员看了一眼铺号，走了。

门帘落下。她整个人抖。她为他圆了谎。圆谎就是入伙。

他把手机屏幕亮给她看：刚才的侧拍，她的脸、他的肩膀、铺号 6 车 12 号中。配上一句：恐高。

尺度：口。必须无声。她跪在中铺，头在他小腹，车轮节奏替他们数。射在嘴里。她咽，因为吐会有味道，对面会问。

她开始求：「到站……求你别……厉北来接。」求本身把「到站前还可以」卖出去了。

### 第五章｜隧道（完成式）

洗漱间早晨排长队。他跟进去「帮你拿洗漱包」。门扣不严。尺度：她面对镜子，他从后面进一半，门外有人拍门「有人吗」。她说「有，马上」。他退出来。精液没有射。欠着。

下午。广播：前方隧道。车内灯灭。七十秒到九十分。同包厢四人都在，黑暗是合法的。

完成式：

1. 他上中铺，黑暗里进去；  
2. 她看得见对面下铺老人的手机微光——他们醒着刷短视频；  
3. 她必须把脸埋进枕，让水声被钢轨吃掉；  
4. 隧道尽头灯亮的前三秒他内射，退出来，帘放下；  
5. 灯亮。她的眼镜歪了。下铺女人把橘子递上来：「姑娘，吃。」她伸手接。手指还在抖。

### 第六章｜出站口

到站前二十分钟。覃可发定位：出站口左手。厉北电话进来：「我加班结束了，改签了后面一班，你先跟可姐走。」

出站。覃可拥抱她，又拥抱自己丈夫：「辛苦你啊。」顾疏衡接过映微的箱子，掌心在她手背上按了一下：夹紧。

三人打车。后座覃可拉着映微的手聊天。映微并着腿，学姐的包就放在她膝上。

收束：酒店前台，覃可订了两间。映微进自己那间，门还没反锁。微信弹一张隧道里模糊的暗部照片，几乎看不清，但够她懂。

配文：票根我留着。下次出门，还坐我下铺。

## 五、本线不写什么

- 不写迷药、不写包厢只剩两人（四人必须在）。  
- 不写终点酒店开苞（开苞/进入必须发生在隧道，身份才是「乘客」）。

# 大纲六｜《乔知夏·样板间》

> 新墙：**售楼处的玻璃与沙盘——楼下全是人，楼上那张展示床却能关门。**  
> 时间盒：开盘前三天内部认购。

## 一、人物

| 角色 | 设定 |
|---|---|
| **韩叙** | 男主。32 岁。销冠。西装合身，话术温柔，擅长把「体验」说成服务。已婚。 |
| **乔知夏** | 女主。26 岁。平面设计师。来看「员工内购」的婚房——不是她的员工价，是男友公司的。腿长，穿平底鞋仍高，看房时习惯按床垫。叫男主「韩经理」，熟了之后被他改成「叫我韩叙就行」。 |
| **阮青** | 韩叙的妻子。售楼处策划，坐二楼主控，面前一面看一楼沙盘大厅的监控墙。样板间卧室没有摄像头——「隐私体验区」。她偶尔下楼送物料，脚步有声。 |
| **左牧** | 乔知夏男友。在一楼填资料、谈贷款、看车位。每隔二十分钟微信：看好了没。他信任销冠，因为「韩经理老婆也在，能有什么事」。 |
| **看房人流** | 玻璃门外的排队。笑声、摇号、香槟。热闹即消音。 |

- 地点：城市新区售楼处。样板间在三楼连廊，需刷工卡。韩叙有。  
- 把柄：她躺在展示床上、背景是样板间假窗的假城市天际线、手腕上还戴着看房时领的贵宾手环。看起来像客户与销冠的床照。

## 二、为什么这容器新

- 「请躺一下感受床垫」「请试衣柜深度」「请体验主卧门的隔音」全是话术，全是合法关门。  
- 阮青的监控墙正好看不见这间卧室——这是她自己定的「隐私」。她越专业，他越好关。  
- 左牧在楼下签字，等于把女友送进体验区。

## 三、三天总线

```
第一日  沙盘、样板厨   → 腰、手、试衣柜；她觉得职业骚扰，没说
第一夜  加班看灯效     → 「夜景卖点」；主卧关门；口；阮青在楼下喊他
第二日  车位地下室     → 柱子后；她开始求「别在左牧来之前」
第二日夜 锁盘值班      → 样板间只剩他们；清醒进入；贵宾手环照片
第三日  摇号           → 左牧中签；交接钥匙时他在她掌心按一下
```

## 四、分章要点

### 第一章｜床垫

开篇他已经在讲：承重墙、得房率、下午茶。乔知夏点头，记笔记。左牧被贷款专员叫走。阮青从二楼探头：「韩叙，三号厅物料。」他应着，把知夏领进主卧。「您按一按。」

她坐下。床是展品，硬。他坐下，弹簧把两人滚近。手从床垫滑到她大腿外侧，「感受独立筒」。她盯着假窗外的假海。他说「门我带上，隔音是卖点」。咔哒，不是反锁，是展示锁，很轻。

尺度：手到裙底为止。门外连廊有另一组客户经过，导购喊「主卧往这边」。他开门，笑着让路。她坐在床上，手环亮着，必须站起来微笑。

### 第二章｜灯效

开盘前夜要调样板间灯光。阮青在一楼陪领导。左牧回家改材料。韩叙说「知夏你眼光好，帮我看暖光还是冷光」。

主卧。灯一暗。尺度：口。她跪在展示地毯上，假落地窗映出她的脸。射在嘴里。楼下忽然阮青喊：「韩叙——U盘！」他抽出，拉裤链，下楼。她还跪着，灯自动感应亮了。

她自己把口红补上，用样板间卫生间的展示牙刷——没拆封——刮舌头。把柄：他回来时已经拍了。她的手环、她的膝、床尾的logo。

### 第三章｜车位

地下车库看车位。左牧被物业拉去量宽度。两根柱子之间。引擎声来回。尺度：从后面进一半，她双手撑在他的车头。左牧远处喊「这边够停」。她必须应「够」。他退出来，没射。欠着。

她开始求：「明天摇号……别搞我。左牧要是中了，这是我们的房。」他把「你们的房」重复一遍，笑：那更该先用过。

### 第四章｜锁盘（完成式）

第二夜售楼处锁门。值班是销冠的义务。阮青回总部改物料，微信：别睡死，明早六点开闸。

样板间。真反锁。她来是因为他把贷款预审资料「忘在主卧」，左牧让她上去拿——左牧的信任把她送上楼。

清醒进入。展示床。假窗外是真的工地灯。她哭，仍不敢大声：保安在一楼中庭巡逻，玻璃能看见人影。

完成式：

1. 贵宾手环不摘；  
2. 他让她看着床头「样板勿动」的牌子；  
3. 内射；把展示抱枕盖在她小腹上，像把展品归位；  
4. 阮青视频打来要U盘位置。他让知夏出镜：「青姐，U盘在我包里。」知夏对着妻子的脸说话，体内还含着。  
5. 投降词：「别给左牧看。也别给青姐看。」

### 第五章｜中签

摇号。左牧中了。香槟喷到知夏的头发上。韩叙作为销冠跟他们合影，手搭在知夏肩上，拇指进领口半分。左牧说「韩经理，以后邻里麻烦你」。

地下车库交临时钥匙。三分钟。左牧去移动车。韩叙把知夏按在他们即将拥有的车位号牌下，最后一次短、狠，射在手心，擦在她手环内侧：「戴回去。中签快乐。」

收束：她坐上左牧的副驾。楼盘沙盘还亮着。微信一张样板间天花板的照片——只有她的耳和那只手环。

## 五、本线尖在哪

- 床不是家里的床，是**商品**。她被当成体验的一部分。  
- 妻子设计了那面「看不见卧室」的监控墙。  
- 男友中签，等于把奸过的展示床买回家。

# 大纲七｜《罗小满·取景》

> 新墙：**相机。它既是工作，也是证人，也是把柄。**  
> 时间盒：甘南三日跟拍。化妆师只在第一日白天，之后只剩摄影师与模特。

## 一、人物

| 角色 | 设定 |
|---|---|
| **裴见山** | 男主。34 岁。旅拍摄影师。口碑「尊重女客、不乱距」。已婚。私底下把取景框当猎场。 |
| **罗小满** | 女主。26 岁。独立来拍一组「一个人的风景」——原计划第三日男友汇合补情侣照。皮白，眉眼深，高原上容易喘，一喘胸就明显。叫男主「裴老师」。 |
| **晏宁** | 裴见山的妻子。后期。不住拍摄地，住镇上。每天收原片，会突然视频「这张焦外是衣服还是皮肤」。她是远程的眼。 |
| **褚衡** | 罗小满男友。第三日下午到。信任裴老师，因为「圈子里口碑好，而且嫂子在做后期」。 |
| **化妆师** | 第一日在。傍晚收工坐大巴回县城。把两人留在牧区民宿。 |

- 地点：甘南。民宿只有两间，老板娘不住宿（季节性）。星空、经幡、山路。风很大，能盖过短促的声音。  
- 把柄：看起来像她在配合的「情绪片」——闭眼、张嘴、泪、锁骨，Exif 里是他的相机。她若声张，行业会先问「你当时为什么还在拍」。

## 二、为什么这容器新

- 「再低一点」「腿打开是构图」「喘是情绪」全是指导，全是侵犯的语法。  
- 妻子每晚看原片，逼他更会藏，也逼小满更不敢删——删了晏宁会问缺了哪一段。  
- 第三日男友入画，要拍情侣，镜头已经先奸过女主一遍。

## 三、三日总线

```
第一日  经幡、妆、指导姿势     → 手摆她的腰、胸、下巴；她当职业
第一夜  星空延时               → 毯子；摸；她说「裴老师，宁姐会看片子」
第二日  无人的山谷             → 口；相机架在三脚架上录；她发现红灯
第二夜  民宿                   → 清醒进入；原片当晚要传后期；她求「别传那几张」
第三日  褚衡抵达               → 三人外拍；镜头里她看向相机后面的他；交接
```

## 四、分章要点

### 第一章｜指导

开篇他已经在说「下颌线」。手指托她下巴，拇指近嘴角。化妆师在旁边刷高光，觉得正常。他让她躺进草里，膝盖打开，「天空才进得来」。裙摆被风掀。他伸手按住，按在腿根，停一秒。快门响。她听见快门就放松——快门等于工作。

章末：化妆师上车。老板娘把钥匙给他：「两间，自己分。灶能用。」他分了：她里间，他外间。门是通的。

### 第二章｜延时

星空要三小时。她裹毯子坐他身边。高原冷。他「调整坐姿」，手从毯下进去。她抓住：「宁姐……」他说：「宁姐要的是星。人是前景。你抖，片子废，她会让重拍。」

尺度：手指。她把脸埋进膝盖。快门每隔三十秒响一次，像在给奸淫打拍子。她高潮边缘时他停，因为「这张要清晰」。她恨快门。

### 第三章｜红灯

山谷。无游客。他架机位：「我到前面对焦，你按这个表情。」他走到她身后，解开自己。口。她跪在经幡下。她忽然看见三脚架上的红灯——在录。她要退。他按着后脑：「这是花絮。宁姐不看花絮。你喊，风会把声音送进村子。」

射在嘴里。他关红灯。回放给她看三秒：她的眼睛、他的手。删除键在他拇指上，没按。

她开始求：「第三天褚衡来。求你当没发生。」

### 第四章｜传片（完成式）

第二夜。民宿外间烧牛粪炉。他要她醒着。进入时她看天花板上的木梁。风把经幡抽得啪啪响。

完成式不是新器官，是**传输进度条**：

1. 他边进边用另一只手连网盘；  
2. 晏宁消息：今晚务必把白天的传了，客户催；  
3. 他让小满自己点「上传」——文件夹里夹着那三段花絮，文件名是 DSC_2077；  
4. 她点了「取消」其中一张。进度条停。晏宁立刻来电：「断了？」小满必须对着妻子说话：「信号不好，裴老师在修路由。」体内他正顶着；  
5. 内射。上传继续。花絮被他改名成「废片-删除」放进私有盘，正片传给妻子。把柄在私有盘。

投降词：「别把废片给宁姐。也别给褚衡。」

### 第五章｜入画

第三日褚衡到。拥抱她，夸「老师拍得真好，你状态好」。三人外拍情侣。裴见山说「衡哥，你站左边，满满看镜头」。她看镜头，等于看他。快门。褚衡亲她额头。他按下快门，说「再来一张，吻长一点」。

收工。褚衡去开车。两分钟。裴见山把相机屏给她看：私有盘缩略图。说：「情侣照我会修得很干净。废片我留着。」

收束：大巴上褚衡睡了。小满翻手机客户群，晏宁发来精修：她站在经幡下笑。精修很美。原片里那双手已经被裁掉。

## 五、本线尖在哪

- 第三者是**后期妻子的审美**。她越要好片子，女主越要配合「再来一张」。  
- 男友入画不是破案，是把奸过的身体重新摆成爱情。

# 大纲八｜《唐疏影·红灯》

> 新墙：**隔音。外面听不见，只看见红灯亮着——以为她在出戏。**  
> 时间盒：一部广播剧突击重录，三夜。

## 一、人物

| 角色 | 设定 |
|---|---|
| **梁穆** | 男主。33 岁。录音师。手稳，耳尖，习惯用手势代替说话。已婚。棚里是他的领土。 |
| **唐疏影** | 女主。27 岁。配音。声音比人有名。本人窄肩、腿长，进棚习惯穿无袖，怕袖口摩擦麦。叫男主「穆哥」。正在录一部很软的爱情广播剧女主，台词里有喘息、有哭腔——这是他选她的原因。 |
| **方芷** | 梁穆的妻子。同公司编导，坐导播间。有时听轨听到一半去写本。红灯亮时她默认「别进棚」。隔音门是她定的规矩。 |
| **童路** | 唐疏影的对戏男声。第二夜才到。第一夜只有她补独白。第三夜三人同棚对戏。 |
| **导演** | 远程，偶尔连线。红灯对他只意味着「正在出货」。 |

- 地点：老城区一间小型录音棚。棚内六平米。导播间玻璃单向偏暗，灯一红，外面更看不见细节。  
- 把柄：工程文件里的「气声轨」。听起来像角色高潮。她若声张，行业会说她戏太入。

## 二、为什么这容器新

- 她的专业就是发出那种声音。真的被侵犯时，外面会以为她在加班。  
- 方芷越尊重「红灯勿进」，门越安全。  
- 童路第三夜入棚，要和她对一段吻戏气口——她的气口已经被别人先用过。

## 三、三夜总线

```
第一夜  补独白、调麦距     → 手调领口、胸麦；越界被解释成技术
第一夜后段 方芷去改本     → 红灯亮着；口；她必须把呻吟收成台词
第二夜  童路晚点           → 空棚两小时；清醒进入；工程轨自动录音
第二夜尾 方芷回听          → 她问「这段你气口怎么这么真」；疏影必须答「入戏」
第三夜  三人时             → 对戏；裤下；收工交接
```

## 四、分章要点

### 第一章｜麦距

开篇他已经在她领口夹麦。指节进无袖边缘，碰到乳侧。他说「摩擦会爆音」。她点头，职业的。试音。她读：「我怕你走。」声很软。他在玻璃那头竖拇指。方芷在导播间敲键盘，没抬头。

调完。他进来「听室内残响」，站得很近。尺度：只到这个近。让她习惯棚里没有一米线。

### 第二章｜红灯

方芷去隔壁改两句。走时说「红灯亮着我就不进，你们先把独白走一遍」。梁穆亮红灯。隔音门吸上。

尺度：口。她跪在吸音棉上。外面方芷若看玻璃，只看见他弯腰「调设备」，看不见她在台下。射在嘴里。他让她立刻对着麦读下一句带哭腔的词。工程软件把精液后的沙哑录进去。他存盘，文件名：女主_独白_take12。

她听回放，发现自己分不清哪一声是戏。开始怕。

### 第三章｜空棚

童路航班延误。方芷在家带孩子，远程听。梁穆说「我们先过情感段」。红灯。

清醒进入。她被放在高脚凳上，麦还夹着。每一下都可能爆音。他故意让她把真实的痛哼读成台词：「不要——」正好是剧本里的词。远程耳机里方芷打字：这句好，留。

完成式：

1. 内射；麦还开着，水声进了轨；  
2. 他剪掉水声，留下气声，发给方芷；  
3. 方芷语音：「疏影今晚状态绝了，跟穆说让她别收那么快」；  
4. 投降词发生在她对着妻子的语音点「收到」的时候。

把柄是 take12 的未删工程文件：有一声不像演技的抽泣。

### 第四章｜对戏

第三夜童路到。帅哥，礼貌。三人棚。吻戏气口：童路靠近她颈侧只出声不碰。梁穆在她身后调麦，裤子里硬着顶她。玻璃外看是正常站位。她必须把顶出来的气音送进对戏。童路夸「你今晚好会」。方芷在导播间鼓掌。

收工。童路先走。方芷上楼拿硬盘。两分钟。梁穆把她按在调音台，最后一次短促，射在她掌心，用防静电布擦掉：「布要扔进耗材桶。别带回家。」

疏影出棚。夜风。微信里方芷发来：明天还你一场，请吃饭，带上童路。

她回：好。

工程文件在梁穆的加密盘。红灯灭了。门开着。下一部戏还约了她。

## 五、本线尖在哪

- 墙不是人，是**职业声响**。她越会叫，外面越满意。  
- 妻子是第一个听众，也是第一句「真好听」的人。  
- 对戏男声第三夜才出现，负责用赞美把脏的气口合法化。
