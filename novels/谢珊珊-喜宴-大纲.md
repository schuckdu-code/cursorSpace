# 《谢珊珊·喜宴》构思大纲

> 人物关系完全沿用《谢珊珊·五日》，剧情、场景、推进手段全部重写。  
> 上一版「离岛封航」废弃，本版改为小城婚礼。  
> 本文只提供大纲，不写正文。

---

## 一、不变项

| 角色 | 关系 |
|---|---|
| 谢珊珊 | 女主。来散心，与男友阿杰处于冷战/暂别。称男主「阿凯哥」。 |
| 晓晓 | 珊珊闺蜜，男主妻子。全程信任两人，不知情。 |
| 阿凯 | 男主，第一人称。晓晓丈夫。对珊珊起意，逐步侵占。 |
| 阿杰 | 珊珊男友。只在对话、回忆、梦呓里出现，本人不到场。 |

- 视角：男主第一人称  
- 尺度：全露骨（与原作同级）  
- 时间跨度：仍是五日，事件全部换掉  
- 心理弧线保留：怀疑 → 知情并隐瞒 → 被把柄锁死 → 清醒承受 → 带着秘密离开  
- 晓晓始终是「在场的墙」：近到能听见呼吸，远到看不见真相

---

## 二、为什么换场景

上一版用海、船、台风把人困在岛上——仍是「旅行 + 封闭住所」，和原作「来上海玩五日」同属度假框架，地理困住也太硬。

本版改成**别人的婚礼**。困住珊珊的不是风雨，是人情：

- 不能当众拆穿，会毁了新娘的正日子，也会毁了晓晓  
- 每天都有合法的肢体接触（敬酒、接亲、闹伴娘、合影、挽扶）  
- 每天都有合法的短暂两人独处（跑腿、取纱、送醉、收桌）  
- 红色、鞭炮、走廊地毯、喜字，替代原作的空调房和岛上的盐

原作与离岛版均不沿用：

- 不用上海一室一厅、电车、迪士尼、影院、迷药、停车场、地铺、KTV  
- 不用渡轮、灯塔、潮间带、包栋民宿、台风停电

---

## 三、新设定

**地点**：江南小城「桐溪」。晓晓高中同学出嫁，缺一个伴娘。晓晓是主伴娘，把珊珊拉来顶缺——理由是「换个热闹环境，别老想阿杰」。阿凯以家属身份随行，临时被抓去充一个次伴郎（开车、搬礼金、挡酒）。

**住宿**：婚礼酒店「满房」。原定两间，被新郎兄弟会挤占。三人拿到一间**亲友套房**：里间大床 + 外间沙发。晓晓拍板：我跟珊珊睡床，阿凯睡沙发，女孩子方便。  
这一分配与原作相反——他不再被赶到车里，他是外间的主人，卧室门是酒店卡锁，他作为「登记入住的丈夫」可以随时刷开。

**五日流程（婚礼本身的节奏，不是旅游行程）**

| 日 | 公开日程 | 阿凯真正要的 |
|---|---|---|
| 第一日 | 高铁抵达、认亲宴 | 套房里的第一道缝 |
| 第二日 | 试纱、布置婚房、踩接亲路线 | 更衣室与别人的婚床 |
| 第三日 | 正婚：接亲、宴席、送入房 | 在几百人的热闹里动手 |
| 第四日 | 回门、主伴娘全程陪新娘 | 空套房里把事做完 |
| 第五日 | 散席、退房、高铁回去 | 喜字还没撕干净之前的最后一次 |

**把柄机制**：不用迷药，也不用「沉睡奸的器官特写」。他拍的是**穿伴娘服、睁着眼、背景里有喜字或婚床**的照片——看起来像婚礼期间的偷情。她若声张，第一句话会变成「你在别人婚礼上勾搭闺蜜丈夫」。

---

## 四、五日总线

```
第一日  满房 / 认亲宴     → 占便宜，她似醒非醒
第二日  试纱 / 布置婚房   → 白天越界，她开始问
第二夜  麻将散场          → 她知情，第一次被迫动手，差点被视频通话撞破
第三日  正席              → 接亲混乱与消防通道；她必须回到席上继续笑
第四日  回门空套房        → 清醒开苞 + 伴娘服照片，投降词出现
第四夜  喜字门后          → 晓晓醉在里间，她醒着被完整侵占
第五日  散席              → 退房前最后一次；电梯里扇耳光；高铁上把柄留下
```

## 五、分章大纲

全书七章。章名全新，事件不复用原作，也不复用离岛版。

### 第一章｜满房（第一日）

**日间**

- 开篇在高铁，不是车站接人、不是甲板。晓晓靠窗补伴娘注意事项，珊珊睡过去，头在颠簸里歪到阿凯肩膀。他没有立刻动手，只借着放外套，让手在她腰侧停了两秒。  
- 桐溪站出口鞭炮味先于人。接亲车队在酒店门口试鸣笛。珊珊第一次看见那么多红：红毯、红喜字、红马甲。她说「太热闹了」。他在心里说：热闹最好，热闹里没人听得见。  
- 前台说满房。晓晓为「两个女生睡床」得意，觉得自己会安排。阿凯帮前台登记，多办了一张房卡，理由正当：半夜可能下楼取东西。

**认亲宴**

- 圆桌，白酒，他坐珊珊侧后方（伴郎席与伴娘席交叉）。敬酒时手扶她后腰「免得她被挤倒」。晓晓在对面拍照，喊「珊珊笑一个」。  
- 他第一次隔着伴娘礼服的薄内衬，用拇指量她腰窝。她侧目，他已经松开，去给新郎点烟。

**夜间**

- 晓晓洗掉妆倒头就睡。里间门虚掩。外间沙发能看见门缝里的腿。  
- 他刷卡进里间，借口找充电宝。两女同床：晓晓靠外，珊珊靠里，酒店空调把被子吹得只盖到腰。伴娘试穿留下的吊带还穿着，肩带滑到臂弯。  
- 尺度：看、闻、隔着内裤用手确认，前端贴着她后颈。她哼了一声。他退到沙发，等她若醒只看见「外间有人起夜」。  
- 她确实醒了一下，看见他站在门边，问「……阿凯哥？」他说「充电。睡吧。」她没有推醒晓晓。  
- 章末：外间黑暗里，喜糖袋子沙沙响。五日从一张多余的房卡开始。

**本章功能**：新空间是酒店套房，不是出租屋。他的合法身份是「登记丈夫」，不是「睡车里的体贴男人」。

---

### 第二章｜试纱（第二日白天）

**婚纱店**

- 主伴娘要帮新娘看效果，晓晓进了最大的试衣间。珊珊在隔壁小间改伴娘服裙摆。店员去找别针。  
- 阿凯「送奶茶」推门。镜子三面，裙子后背拉链只拉到腰。他从后面帮她拉拉链，拉上去，再拉下来，手贴着裸背。  
- 她想喊店员，他低声：晓晓就在隔壁，墙是一层板。「你现在叫，她先看见你没穿好。」  
- 尺度：镜子里的手从腰滑到胸下沿，再从裙摆探入，不进去，只让她看清自己被摸时的表情。店员敲门「别针找到了」。他退到门后。珊珊当着店员的面把拉链拉好，手在抖。

**下午：布置婚房**

- 新郎新娘的婚房在酒店另一栋。晓晓跟新娘去挑手捧花。伴娘伴郎被派去铺床、撒花瓣、吹气球。  
- 别人出出进进。等人走光拿胶带时，他把珊珊按进那张还没被新郎新娘用过的婚床。红床单、喜字枕。  
- 尺度：掀伴娘裙、用手、用嘴，做到她快出声，门外忽然有人喊「气球不够」。他停。她必须自己把花瓣从头发里摘掉，再若无其事出去要胶带。  
- 心理：脏的不是「在床上」，是「在别人的喜床上」。她开始恨自己为什么还在帮着铺平那张被她抓皱的床单。

**傍晚：接亲路线踩点**

- 面包车里九个人。她被挤在他与车门之间。颠簸让接触有了借口。他的手在她大腿外侧，别人只当拥挤。  
- 她第一次压着声音问：「你昨晚是不是进过里间？」  
- 他看窗外，说：「充电宝。你要是问晓晓，她会问你为什么当时不醒我。」  
- 问完她就后悔。羞耻开始替他工作。

**本章功能**：从不确定推进到「问了一句」。场景是试衣镜和别人的婚床，不是乐园和沙发。

---

### 第三章｜视频通话（第二日夜）

**新娘家麻将**

- 晓晓手气好，被老太太按着不能走。她让阿凯先送珊珊回酒店，「我打完这圈就打车」。  
- 珊珊想留下，晓晓已经把她的包塞过来：你明天接亲要早起。

**回套房**

- 电梯监控让他没动手。进门之后才卡死防盗扣。  
- 她背靠墙：你到底要怎样。出现「求」。  
- 尺度：逼她用手。理由新做：酒店墙薄，他自己动，皮带和沙发会响；她的手没有金属声。  
- **差点穿帮的方式全新**：不是门外脚步，是晓晓的视频通话打进来。珊珊必须接——主伴娘在问「房间空调密码多少」。他让她把手机举起来，镜头对着天花板和喜糖，他自己跪在镜头盲区，把她的手按回去。她一边报「8888」，一边哭得无声。晓晓在麻将桌那边笑：「你声音怎么哑了？是不是认亲宴喝多了？」她说：「……烟味。」

**收束**

- 晓晓十二点多回来，身上全是烟和喜糖。她倒在床上还亲了珊珊一下：「辛苦你了，明天你跟我挡门。」  
- 珊珊掌心已经擦过，却总觉得黏。她把用过的纸巾塞进自己的化妆包，没有扔进垃圾桶——怕晓晓看见。  
- 阿凯在外间听她们说话，知道锁扣已经咬上：她开始自己藏赃。

**本章功能**：替代原作影院纸巾团。藏赃发生在视频通话之后、化妆包里。

---

### 第四章｜正席（第三日·婚礼当天）

**早：接亲**

- 伴娘挡门、整蛊新郎，场面乱、笑、起哄。阿凯作为临时伴郎，有合理身份挤在门后。  
- 他不写集体「闹伴娘」。别人的玩笑到此为止。他只在起哄的缝里下手：递挡门的辣椒时指节擦过她唇；堵门游戏「找红包」时手伸进她裙侧口袋，停在腿根，外面一群人喊加油。  
- 她不能发怒。发怒会变成「伴娘耍脾气，婚礼要黄」。晓晓还在门口摄像，边拍边喊「珊珊你挡得好！」

**午：宴席**

- 几百人，音响、敬酒、转桌。珊珊要跟主伴娘一起给长桌敬酒。  
- 他中途拉她「去拿备用红包」。消防通道，门一关，鼓点还在震。  
- 尺度：口。短、狠、她妆不能花。射在口里，检查她咽下去，再给她补口红——用的是晓晓包里那支，早上塞给他「帮珊珊带着」。  
- 她回到席上时，晓晓拉她敬下一家：「笑！镜头在拍。」她笑了。酒杯沿碰到刚被使用过的唇。

**晚：送入房之后**

- 新郎新娘进婚房，亲友仍在喝。晓晓去送嫁妆。  
- 他没有当晚开苞（正婚日太满，也太容易被找人）。只在走廊把她按在喜字墙下，让她看自己被补过的口红，说：明天回门，晓晓会离开一整天。你自己选，是今晚在这面墙下叫，还是把这五日熬完。  
- 她没叫。喜字在她后脑后面，金粉掉在头发里。

**本章功能**：替代乐园黑暗与影院。公众场合的「不能拆台」比物理封闭更有效。最高尺度停在口，把开苞留给空房——让第四日更尖。

---

### 第五章｜回门（第四日白天）

**空窗怎么来（不用装病、不用迷药、不用支去寺庙）**

- 回门是主伴娘的义务：晓晓必须跟新娘回婆家一整天。珊珊不是主伴娘，可以留在酒店「看行李、收份子钱账本」。她以为这是逃生窗口。  
- 阿凯「把礼金账本忘在套房」，从回门车队里退出来。前台认他房卡。

**空套房**

- 她用防盗扣。他从外间打电话给她：你不开，我就给晓晓发两张试纱间的镜子照片，问她为什么伴娘服拉链是开的。  
- 她开了。醒着、骂、推。  
- 他压她的不是暴力，是两句话：  
  1. 晓晓此刻正在别人家里为这段婚姻当喜神；  
  2. 你前两天接过视频、咽过东西、在消防通道消失了七分钟，现在才喊，谁信。  
- 尺度：清醒破处。红还没从酒店地毯上撤干净。她喊阿杰。他纠正：不是阿杰。  
- 拍照策略：伴娘服只褪到腰、胸前襟花还别着、背景是落地窗外的桐溪河和窗玻璃上倒贴的喜字。睁眼。咬手。这组照片的杀伤力是「像偷情不像强奸」。

**穿帮边缘**

- 晓晓发来回门面的照片：猪蹄、枣子、她自己笑得很满。「珊珊你在干嘛呀想你了」  
- 他让珊珊回：睡觉，头有点疼。发送的时候他正在里面。她把「疼」字打对，发送键按下去，人却在抖。

**傍晚**

- 晓晓回来，进门就摸珊珊额头：「你真不舒服？那晚上余宴你别喝了，我包里有红糖。」手按在她小腹上。珊珊说「可能要来例假」。这句话是投降。  
- 晓晓洗澡时，他在外间把照片划给她看。条件：剩下的夜里，防盗扣别再扣。散席之前，你还是那个会笑的伴娘。  
- 投降词：「别给晓晓看。」

**本章功能**：开苞从沉睡改为清醒，从「岛上空屋」改为「回门留下的酒店套房」。把柄是伴娘服与喜字，不是迷奸特写。

### 第六章｜喜字还在（第四日夜）

**余宴不做 KTV**

- 酒店二楼包了两桌家常菜给亲友收尾，不是唱包厢。晓晓挡酒挡到站不稳。珊珊必须把她扶回套房——这是主线，不是支线。  
- 晓晓倒在里间，卸了一半的伴娘妆，还说「明天送他们去机场」。呼吸很快变沉。

**几何关系全新**

- 不是同床地铺，不是杂物间门缝。是：里间门开一条缝，晓晓醉卧；外间沙发是他的床；喜字贴在套房门外的走廊里，偶尔有醉汉走过、敲门问「冰桶」。  
- 他要她醒着，在外间做。门缝里能看见晓晓的小腿。若她叫，里间那个人会用醉觉里最信任的声音问「珊珊？」

**尺度与完成式**

- 不靠换一个器官当完成式（后穴不作主线必写）。完成式是身份：  
  1. 伴娘服还没脱干净，襟花歪着；  
  2. 他让她看着里间那条缝，进去；  
  3. 有人敲门要冰桶时，她必须自己说「没有，别敲了」，声音要像没事的伴娘；  
  4. 要她在清醒里被身体背叛——高潮来的时候她咬他肩膀，恨的是自己；  
  5. 内射。她求外射、求怕怀孕。他偏内射。退出来后把襟花别回原处，像把礼物重新包装。  
- 她爬回里间。晓晓手臂搭上来，醉里叫「珊珊……今天好圆满」。她夹着东西，面向天花板，听走廊里还有人唱《婚礼进行曲》的走音版。

**本章功能**：替代地铺与台风客厅。墙是门缝，喧嚣是走廊醉汉，完成式是「喜字还没撕、妻子还在缝里、伴娘服还在身上」。

### 第七章｜散席（第五日）

**清晨**

- 走廊服务生开始撕喜字，胶还黏着。晓晓下楼结账、买车站点心。套房里剩两个人，十分钟。  
- 最后一次短、狠，不开发新部位，只要她夹着去赶高铁。发生在里间那张她和晓晓同睡过的床上——晓晓的充电器还插在床头。  
- 她在他抽出之后扇了他一耳光。打完仍要压着声音，因为门外有人推着布草车经过。

**高铁**

- 三人一排。晓晓靠着他睡，手里还攥着新娘送的伴手礼。珊珊靠窗，看桐溪向后撤。  
- 他低头看手机，像在看路书，实则把相册加密。经过她时只剩一句：「照片留着。想安静，就当这五日是别人的喜事。」  
- 她问：「会删吗？」  
- 「不会。」

**收束意象**

- 原作收在上海夜色，离岛版收在船尾。本版收在高铁窗：一座小城的红从视野里淡掉，喜字被撕下的胶痕却还在酒店门上。  
- 婚礼结束了。伴娘服会还回去。把柄和体内的脏还不回去。  
- 最后一句落到「散席」，不落到床上：她来讨一点热闹，把别人的喜事过完；他把她留在那张红床单的褶皱里。

## 七、人物心理（五日）

**谢珊珊**

- 第一日：把不安解释成酒和累  
- 第二日：问了一句，发现问比不问更危险  
- 第二夜：开始自己藏赃  
- 第三日：必须在镜头前笑；发现热闹是他的同谋  
- 第四日：怕的不是痛，是晓晓会把她看成在别人婚礼上插足的人  
- 第四夜：为了掩护而对走廊陌生人说话；身体在门缝对面背叛她  
- 散席：恨他，打他，仍替他保密

**晓晓**

- 全程热心、爱拍照、把伴娘义务当荣耀  
- 每一个「缺席」都出自情义：帮新娘看纱、打牌被按住、回门、挡酒、下楼结账  
- 她越想把婚礼办圆满，阿凯越好下手

**阿凯**

- 新的计算题是：房卡、试衣间隔板、接亲的起哄、敬酒的空档、回门的人员配置、走廊醉汉的脚步  
- 快感仍来自「近」：不是把晓晓支到岛的另一头，而是让她在门缝里、镜头里、麻将桌那头
