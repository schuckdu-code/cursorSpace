# 新小说大纲合集

> 对照现有作品之后新开的四条线。本文只提供大纲，不写正文。  
> 视角一律男主第一人称；尺度一律全露骨；角色均默认 22 岁以上。

---

下面四条线换的是：**时间盒、空间盒、把柄形态、第三人是谁**。公式保留——信任当润滑、沉默变共犯、近处有人比空屋更硬。

---

## 总原则（四条线共用）

1. **不复用迷药配方场面**作为开苞主手段（正作第四章已经用过）。新线用酒、疲惫、伤口、人情、房卡、钥匙。  
2. **把柄尽量长得像偷情不像强奸**：睁眼、背景里有合法第三者的痕迹（男友拖鞋、姐姐的年夜饭围裙、病号服、对门门牌）。她一闹，第一句话会变成「你自己也在场，为什么当时不喊」。  
3. **完成式走身份置换，不走器官清单**：同一器官可以再用，但必须换「她此刻是谁」——女友、姐姐、病人、邻居。后穴不作默认主线，除非那条线的空间特别适合（例如病房隔帘后的无声）。  
4. **晓晓可以在场，也可以只在语音里**；但不能再当唯一的墙。四条线各自换一块新墙。

# 大纲一｜《谢珊珊·来接》

> 正作续篇。不用婚礼、不用伴娘、不用婚纱、不用桌布。  
> 新墙：**阿杰本人到场**。

## 一、为什么是这条

《五日》收在车站。她走了，视频留下，晓晓仍不知情。  
《喜宴》把她重新丢进别人的红里。  
这条线把**她自己的男友**请到那间一室一厅里——不是回忆、不是梦呓、不是电话，是一个会刷牙、会吃醋、会跟阿凯敬酒的活人。

困住她的不是天数，是四个人挤在原作同一套房子里：她必须同时当好女友、好闺蜜、好客人。任何一声「不」都会让三个人同时听见。

## 二、不变项与新项

| 角色 | 关系 |
|---|---|
| 谢珊珊 | 女主。五日之后三个月。称男主「阿凯哥」。 |
| 晓晓 | 仍不知情，反而更热情：觉得珊珊「想开了」，主动邀请小两口来玩。 |
| 阿凯 | 男主。视频仍在云端。 |
| 阿杰 | **首次到场。** 26 岁，外企销售，会说话，对「晓晓老公」感激到近乎谄媚——上海那五天「照顾了珊珊」。 |

- 时间：国庆七天假，实际写五日（抵达、同住、一日游、醉酒、离开）  
- 住宿：仍是那间一室一厅。晓晓拍板：小两口睡卧室，我们打地铺——**分配与正作完全反过来**。阿凯不再被赶到车上，他是客厅的主人；珊珊每晚和阿杰睡在她被破处、被内射过的那张床上。  
- 把柄：旧视频仍在；新把柄是「当着阿杰拍的、看起来像她主动」的照片（她睁眼、男友的背包在画面边角）。

## 三、五日总线

```
第一日  接站四人   → 他闻见她身上的男友味；第一道缝在卫生间
第二日  外滩合影   → 白天合法贴靠；她开始用眼神求「别在他面前」
第二夜  地铺       → 阿杰睡觉轻；她必须自己压声，把柄照片诞生
第三日  男友回公司远程 → 空窗两小时；清醒再占有；她求「射外面，他会发现」
第四日  晓晓同学局 → 酒；阿杰去买醒酒药的二十分钟
第四夜  同一张床   → 阿杰醉死内侧，她醒着被从外侧进入；完成式
第五日  送站       → 四个人拥抱；她夹着东西上高铁；把柄从一份变成两份
```

## 四、分章（七章）

### 第一章｜四个人的门

高铁出站。晓晓去买奶茶。阿凯看见他们十指交扣走出来。珊珊看见他就僵，阿杰却先伸手：「阿凯哥！上次真麻烦你。」

握手。阿杰手热、亮、无辜。阿凯在心里笑：你握的这只手，三个月前刚把她的血擦掉。

一室一厅。晓晓兴奋布置：新四件套、「给小两口用」。珊珊换床单时手抖——她认得这张床的尺寸。阿杰夸「你们感情真好」。

夜间。阿杰先睡。珊珊去卫生间洗脸，门没插严。阿凯「接水」，进去。尺度：抵住洗手台，隔着睡衣确认三个月后的身体，不进入。她咬牙：「他在外面。」阿凯只问一句：「视频，还要不要他看？」她把水龙头开到最大。章末：她回到卧室，阿杰迷迷糊糊伸手搂她。她让他搂。阿凯在地铺上听那张床响了一下——只是翻身。

### 第二章｜合影的手

白天外滩。晓晓要合影：两对。阿凯站珊珊身后「摆姿势」，掌心在她腰窝停三秒，镜头里是祝福。阿杰说「哥你手往上一点，挡住我肩膀了」。他往上，擦过胸侧。珊珊笑裂了。

下午室内。阿杰打游戏，戴耳机。晓晓做饭。阿凯进卧室「找充电宝」（正作梗翻转：这次床上坐着她男友）。尺度：门半掩，他让她用手，耳机麦是开着的——阿杰突然说话「这把赢了」，她必须应「真厉害」，掌心还握着东西。差点穿帮。

她第一次用气声求：「别在他面前。你要怎样我回上海再……」这句话是裂缝：她开始拿「以后」换「现在」。

### 第三章｜地铺听呼吸

晓晓十一点睡死。阿杰侧卧，面朝墙，呼吸并不很沉。阿凯在地铺等了四十分钟。

他不上床。他把珊珊叫下来——用旧视频预览亮一下屏幕。她爬到地铺。五十厘米外是晓晓，两米外是阿杰。

尺度：口。短。她眼泪掉在他小腹。射在嘴里。检查咽下去。拍照：她的脸、她身后虚焦的床——床上有阿杰的小腿。

她自己把纸巾塞进睡衣口袋，没有扔。藏赃再次发生，但这次赃是「怕男友看见」而不只是怕晓晓。

章末：她爬回床。阿杰翻身，鼻子拱进她颈窝：「你刷牙了？薄荷的。」她说「刚洗过」。薄荷味底下是精液。她没吐出来。

### 第四章｜远程那两小时

阿杰所在公司国庆仍有值班。上午必须回一小时视频会议，用客厅。晓晓被同学拉去逛折扣。珊珊以为自己可以锁卧室。

阿凯有房门钥匙。他把会议的声音当掩护：客厅里阿杰在说「同比、环比」，卧室里他让她看着门缝。

尺度：清醒进入。三个月后的身体不是处，却因紧张而紧。她求外射——「他晚上会要。他会发现太滑。」阿凯偏内射。逻辑肮脏：让阿杰今晚操到含着别人的东西。

穿帮边缘：会议结束，阿杰敲门：「珊珊，你睡了？开门。」她必须在三十秒内穿好、夹紧、去开门。阿杰进来亲她，说「好想你」。手往下滑。她按住：「下午……晚上。」阿杰以为她害羞。

### 第五章｜醒酒药

晚上晓晓同学局。四人同行。酒局闹。阿杰被灌，珊珊挡了一部分，仍醉。阿凯倒得少。

回程。阿杰在便利店门口说头痛。晓晓让阿凯陪他。阿凯说：「我上去拿常备药，阿杰你在这儿吹吹风，两分钟。」晓晓在车里等。便利店监控对着门口。

两分钟不够。真正的空窗是：阿凯拉珊珊「上楼拿药」，阿杰坐在塑料凳上按太阳穴。

上楼。电梯监控。进门。反锁。尺度：按在玄关鞋柜上，从后面进，不脱裤子只拨开。射在里面。给她一盒真的布洛芬。下楼。全程六分半。

阿杰接过药：「哥你太够意思了。」珊珊站在灯下，腿根还在抖。晓晓探头：「药拿到了？走啊。」

### 第六章｜同一张床（完成式）

阿杰喝了药又被晓晓哄着喝了蜂蜜水，睡得前所未有的沉。晓晓在地铺，耳机听播客，其实很快睡着。

几何关系全新：不是地铺奸她，是**上她和男友的床**。阿杰睡内侧靠墙，她睡外侧。阿凯掀开外侧的被子。

完成式不是新器官，是身份：

1. 她穿着阿杰的T恤当睡衣；  
2. 阿杰的手臂搭在她腰上；  
3. 阿凯从外侧抬起她一条腿，进入时她必须自己按住阿杰那只手，别让他被顶醒；  
4. 有一次阿杰含糊叫「珊珊」，她必须应「嗯，我在」，同时被顶到最深；  
5. 内射。她哭着求拔出去。他不拔。退出来后把阿杰的手重新放回她小腹——小腹底下是刚射进去的东西。

她面向阿杰的背。阿凯回地铺。黑暗里三个人的呼吸：一个醉，一个装睡，一个高潮后平静得像没事的丈夫。

### 第七章｜送站

清晨。阿凯在卫生间「最后一次」，短、狠，射在腿根，让她夹着去赶高铁。她出来后扇他一耳光。打完立刻去给晓晓化妆包拉链——门没关严，晓晓在问「拖鞋收了没」。

站台。四个人拥抱。阿杰用力抱阿凯：「以后常来，亲兄弟。」珊珊看地面。晓晓给她塞零食。

高铁上阿杰靠着她睡着。她看窗外。手机震一下。阿凯发来一张加密相册的缩略图：昨夜，她的侧脸，背景是阿杰的肩膀。

配文：两份了。一份给晓晓看的，一份给他看的。你选安静。

收束意象：正作收在上海夜色，喜宴收在高铁窗与喜字胶痕。本篇收在**四张连座票的中间两张**——她和阿杰坐一起，阿凯和晓晓坐前排。前排男人按下锁屏。后排女人把腿并拢。

## 五、本线不写什么

- 不写迪士尼、影院中间座、迷药、KTV厕所、停车场对质（那些是正作）。  
- 不写婚礼、伴娘、红毯（那些是喜宴与番外）。  
- 开苞已发生，本线的尖不在「第一次」，在「当着第一次爱她的人，做第 N 次」。

# 大纲二｜《陈书意·守岁》

> 新女主。不进谢珊珊宇宙。  
> 新墙：**一整个过年的家**——父母、视频、亲戚、炮仗。

## 一、设定

| 角色 | 设定 |
|---|---|
| **陈书意** | 女主。27 岁。晓晓的亲姐（若要独立宇宙，则改为男主妻子的亲姐）。已婚两年，丈夫何予年三十必须留在外地值班。性格比晓晓稳，会持家，漂亮得不张扬：锁骨深、腰细、婚后胸更沉。叫男主「凯子」或「阿凯」——从小叫到大，没有「哥」的敬，只有姐弟间的熟。 |
| **晓晓** | 妹妹。热衷把姐姐从「冷清年夜」里捞出来。 |
| **阿凯** | 男主。对姐姐的欲望早于对珊珊——只是从未有过封闭五天。过年给了他。 |
| **何予** | 书意丈夫。不到场。每晚视频。声音成为新的消音器。 |
| **父母** | 可在邻市，每天视频拜年；或住同一小区楼上。推荐：**住楼上两层**，随时可能敲门送饺子。比同屋更尖——来得合法，走得突然。 |

- 地点：上海，男主与晓晓的两室一厅（可比正作大一号，否则四人过年太挤；书意睡客房）。  
- 时间：年二十八到初二，五日。  
- 把柄：守岁夜她睁着眼、背景是电视里的春节联欢晚会台标；或她穿着姐姐的围裙、窗上有倒福。看起来像「过年偷情」。

## 二、为什么不是五日旅行

过年的封闭是人情封闭：

- 不能吵，楼上父母会问「小两口是不是打架」；  
- 每天都有合法接触：包饺子、擦窗、换灯笼、帮她铺客房、帮她拧红酒；  
- 每天都有合法独处：晓晓回娘家楼上「陪爸妈打牌」，嘱咐「你陪姐说说话，她一个人怪可怜」；  
- 红色、炮仗、福字、饺子馅的肉腥，替代原作空调房。

## 三、五日总线

```
年二十八  接姐          → 熟不拘礼的第一道缝（围裙、后背）
年二十九  扫房备年       → 客房床垫；她开始皱眉，仍当小舅子没规矩
年三十    守岁           → 晓晓上楼打牌；电视春晚；视频通话里被迫用手
初一      拜年空窗       → 三人去父母家，她「姨妈疼」留守；清醒进入；倒福照片
初一夜    客房           → 楼上敲门送桂圆；她必须自己去应门；完成式
初二      送站           → 高铁回丈夫；把柄留下；她说「明年别接我了」
```

## 四、分章要点

### 第一章｜姐来了

接站不用虹桥煽色。重点写熟：她自然把行李箱给他，自然拍他肩膀，「一年不见，你怎么还是不爱梳头」。晓晓扑上去叫姐。三人回家。客房铺床，晓晓去楼上拿新被子。他帮书意套被罩，两人隔着棉被对扯，手在布料下碰到她的手。她笑骂「没正形」。尺度停在：她弯腰塞床单，家居裤腰露出一截内裤边——已婚女人的日常，不是邀请，被他当成邀请。

夜。她洗完澡出来，头发湿，穿晓晓的旧睡衣（偏小）。胸被勒住。她自己也愣了一下，说「你们衣服都这么小」。他看了两秒太久。她把脸扭开。

### 第二章｜扫房

白天合法脏：擦灯，她在凳子上，他扶凳，脸平她髋。她说「你看哪儿呢」。他说「怕你摔」。尺度：客房试床垫弹性，她坐下去，他坐旁边，弹簧把两人滚到一起。她撑起来，脸色变了。第一次认真的停顿。

晚。何予视频。她坐客厅，他在镜头外给她削苹果，削完把果肉递到她嘴边。她下意识咬。晓晓在镜头里喊「姐夫年三十加油」。何予看不见递苹果的手。

### 第三章｜春晚（知情）

年三十。父母留晓晓上楼守岁打牌「缺一门」。书意要跟，晓晓按住：「姐你陪凯子！他一个人看春晚多惨。爸妈又不是外人。」

两人看春晚。他喝酒，她陪了一杯。零点倒计时，炮仗把窗户震得发颤。他吻她——不是强暴式的第一下，是「跨年」借口。她推开，扇了一下，不重。「我是你姐。」

他把她的手按在裤裆：「现在不是。」

尺度：沙发上手活。春晚歌声极大。何予的跨年视频打进来。她必须接。他跪到镜头下方（喜宴视频通话的功能在这里换春晚与丈夫，不换结构就换对象）。她说「宝宝跨年快乐」，手没停。何予：「你声音怎么哑？」她：「炮仗。」

藏赃：纸巾进她自己的化妆包。她开始怕晓晓从楼上下来看见沙发。

### 第四章｜姨妈

初一。上门拜年。她说腰坠、要来例假，留守。晓晓信。父母信。嘱咐阿凯「饺子热了给姐送上去」——他留在家里。

空房。她用防盗扣。他打电话：不开，就把春晚那张「你手的位置」发给何予。她开了。骂、推、哭，仍不敢大声——楼上父母的脚步有时能听见。

尺度：清醒进入。已婚不是处，尖在「婚戒还戴着」。他让她看着戒指操进去。拍照：围裙、倒福、婚戒、睁眼。

何予发来拜年红包封面。她回复「也爱你」的时候他正在里面。

投降词：「别给何予看。也别给晓晓看。」

### 第五章｜桂圆（完成式）

初一夜。晓晓在楼上被留宿「爸妈想女儿」。客房只剩他们——但不是岛，是随时会被敲门的家。

他要她醒着。做到一半，门铃响。母亲的声音：「书意，桂圆，补补。」

完成式：

1. 他不拔出来，按住她；  
2. 她必须自己套上睡袍，夹着他走到防盗门；  
3. 门开一条缝，接过桂圆，说「谢谢妈，凯子睡了」；  
4. 母亲看见她锁骨的红，以为是暖气；  
5. 关门后他从后面重新进去，内射。桂圆袋子还提在她手里。

她把桂圆放进冰箱。塑料袋沙沙响，像正作里的喜糖，但是年味。

### 第六章｜初二早上

晓晓下楼进门：「姐你脸怎么这么白？」书意说没睡好。三人吃桂圆煮鸡蛋。母亲的桂圆。她咽下去。

送站。她在车里很轻地说：「明年别接我了。」不是原谅，是求饶。他不答。手机里倒福照片加密。

高铁启动。她发信息给何予：「上车了。想你。」发送时腿仍并着。

## 五、本线尖在哪

- 第三人不是闺蜜，是**丈夫的声音 + 父母的饺子**。  
- 她不能说「强奸」，因为过年的家会先问「你怎么不早说」，再问「是不是你也喝多了」。  
- 完成式是应门，不是新器官。

# 大纲三｜《梁秋白·陪床》

> 新女主、新男主。不用诊所（避开《白大褂》），不用酒店（避开《出差搭房》）。  
> 新墙：**病房隔帘、护士查房、同室病友**。  
> 新的身体限制：她插着留置针，腰不能用力，跑不了。

## 一、设定

| 角色 | 设定 |
|---|---|
| **周宴** | 男主。32 岁。表面是靠谱的「家属代理」。妻子徐晚出差三天，临走把闺蜜托付给他：「秋白胆囊手术，她男朋友在外地赶不回来，你去陪床，当自己妹妹。」 |
| **梁秋白** | 女主。26 岁。小学教师，皮肤白，腰细，因长期站讲台小腿线条好。胆囊微创手术后需留院观察两夜 + 出院后再静养两日（共五日叙事）。怕疼、怕给别人添麻烦、极讲究体面。叫男主「周哥」。男友姓谭。 |
| **徐晚** | 周宴妻子，秋白闺蜜。全程语音在场：叮嘱吃药、问「我老公烦不烦你」。 |
| **谭屿** | 秋白男友。外地出差，第四日才能赶到。视频里感谢周哥。 |
| **同室** | 隔帘那边是一位五十多岁的胆囊术后阿姨，耳背，睡得早，偶尔半夜喊护士。她是活的隔音墙，也是随时会按铃的炸弹。 |

- 地点：市立医院肝胆外科，双人病房。陪护椅折叠，窄，紧贴病床。  
- 把柄：病号服掀到胸口、留置针、腕带姓名、背景是输液架。看起来像「陪护乱伦/偷情」，她若报警，第一句话会变成「你为什么不按铃」。

## 二、为什么这个容器新

- 灯是永远不灭的廊灯。  
- 十五分钟到两小时可能有人推门：护士、护工、查房。  
- 她的身体本身就是锁：伤口、输液、止痛泵按键在他手里。  
- 「照顾」是徐晚亲自授权的合法外衣，比晓晓的信任更硬——因为有医嘱和签字。

## 三、五日总线

```
入院夜   手术回来   → 她昏睡；他在陪护椅上看、闻、隔着病号服确认
第一日   下床行走   → 「搀扶」合法摸腰；厕所门口超时
第一夜   止痛泵      → 她清醒怕疼，求他按泵；他用泵换口
第二日   徐晚视频    → 镜头前是好姐夫；帘后是手
第二夜   同室熟睡    → 清醒进入；查房脚步在走廊；内射在病号裤里
出院日   谭屿赶到    → 交接；她夹着东西让男友扶她下楼
```

## 四、分章要点

### 第一章｜陪护椅

手术结束已是夜里。徐晚的语音：「她麻醉还没全醒，你看着点滴，别睡着。」秋白被推回来，脸色纸白，唇干。病号服在脖子里皱着。他帮护士「侧一下身」，手掌经过胸侧。护士夸「家属真会」。

夜。她哼疼。他喂水。尺度：掀病号服下摆看伤口敷料（合法），看完视线停在没有伤口的小腹和裤腰。隔着病号裤按住缝，只确认。她迷糊抓住他的手腕：「……谭屿？」他说：「周哥。睡。」她没有按铃。

### 第二章｜走路

医嘱：下床走。他扶。她整个人挂在他手臂上，胸贴他小臂。厕所他要跟进去「防摔倒」。她拒绝。他站在门外面，门没锁死——医院厕所门常关不严。尺度：她出来时他伸手整理她后腰系带，手指进裤腰。她瞪他。他说「带子散了会走光」。她无法解释给走廊里的护士听。

徐晚视频：秋白笑着说「你老公太尽职」。周宴在镜头外看着她的笑。

### 第三章｜止痛泵

第一夜她疼醒。止痛泵的按钮在床栏上。他按住她的手：「按太多会吐。你先帮我……我就给你按。」

病房不是KTV。尺度必须无声：口。帘子拉上。同室阿姨打呼噜。走廊鞋底。她含着，眼泪掉在病号服上。射在嘴里。她咳，他用手捂。护士恰巧推门：「还好吗？点滴快完了。」帘内她咽下去，说「做噩梦」。护士换瓶，走。把柄照片：腕带、输液管、她的嘴。

她开始求：「等谭屿来……你别……我欠徐晚的，我不会说。」求本身就是许可的赝品。

### 第四章｜帘

第二日白天探视多。他白天规矩。下午徐晚视频要看伤口。秋白把手机给周宴「帮我拍一下敷料」。他拍敷料，另存一张更下面。

夜。同室阿姨吃了安眠药。他上病床——陪护椅太窄，这是完成式的几何：病床护栏放下，他侧躺挤进去，像合法的「怕她坠床」。

进入必须慢，怕床响。她咬自己的留置针那只手的虎口。走廊出现查房车轮声。他整根埋着不动。护士在邻床喊「王阿姨，血压」。帘子一动。秋白的眼睛瞪到极限。车轮走远。他才动。内射。病号裤拉上。精液在里面，外面看是一个被照顾得很好的术后病人。

### 第五章｜交接

谭屿飞机延误，出院当天中午赶到，眼睛红，抱住秋白：「辛苦你了，也辛苦周哥。」周宴把药袋、出院小结交到谭屿手里，掌心贴过秋白的后腰，像嘱咐「别提重物」。

电梯里三个人。谭屿去按楼层。周宴在秋白耳后无声：夹紧。她看着数字跳动。

地下车库。谭屿去开车。三分钟。周宴把她按在消防栓箱上，最后一次短促，不进入，只让她用手，射在她掌心，用她自己的消毒湿巾包起来：「扔掉。别带上车。」

她坐进男友的车。周宴在后视镜里消失。手机里一张腕带照片。徐晚发来：「我老公人吧？回来我请你吃饭。」

秋白回：人很好。

## 五、本线不写什么

- 不写医生身份作案（那是《白大褂》）。他是家属，罪在「被托付」。  
- 不写迷药。麻醉余韵只用于第一章，开苞/进入放在她清醒、怕疼、怕按铃的第二夜。  
- 不写多女患者并列。只这一张病床。

# 大纲四｜《何棠·对门》

> 新女主、新男主。不用合租同屋（避开杨宝斐线），不用短住酒店。  
> 新墙：**两户门、一把备用钥匙、物业监控、她自己的家**。  
> 时间盒拉长为十四天里的五个「合法进入夜」，正文仍可写成七章。

## 一、设定

| 角色 | 设定 |
|---|---|
| **沈倦** | 男主。29 岁。设计师。妻子罗敏常驻杭州项目，两周一回。表面好邻居：收快递、修水管、换灯泡。 |
| **何棠** | 女主。25 岁。独立插画师，在家办公。对门 1204。男友在新加坡轮岗，三个月一回。性格软、怕给邻居添麻烦、习惯把备用钥匙「拜托靠谱的人」。腿长，居家常穿短裤背心，并不防备同层的已婚男人。叫男主「沈哥」。 |
| **罗敏** | 沈倦妻子。微信里催他「多帮棠棠，女孩子独居」。授权再次来自妻子。 |
| **裴舟** | 何棠男友。时差。每晚视频，能看见她房间背景——这是把柄与穿帮的双重来源。 |

- 地点：同一层 1203 / 1204。两扇门相对。猫眼能看见对面门厅。  
- 合法进入理由链：收快递 → 代浇绿植 → 她出差两天托他喂猫（猫是新道具）→ 水管爆了 → 停电找手电。  
- 把柄：在**她自己的床上、她自己的电脑桌前**拍的睁眼照片，背景有裴舟的合影相框。她一闹，像「趁男友不在约已婚邻居」。

## 二、为什么这个容器新

合租是「共享私人空间」。对门是「她把家门的牙模交给你」。每一次插入都发生在她以为安全的坐标里：她的杯子、她的床单、她的猫。奸完他走回自己家，洗一把脸，回妻子消息：帮她修了水管。门一关，两户仍是好邻居。

## 三、十四日里的五个夜（写成七章）

```
第1次进入  快递堆在她家门口，她在开视频，让他放客厅  → 只看、只靠近
第2次      她出门取稿，托他喂猫          → 抽屉、内衣、第一张偷拍（尚未用来威胁）
第3次      她回来当面道谢，留他喝饮料     → 沙发越界；她说「沈哥，罗姐会怎么想」
第4次      水管；他关总阀，进门；湿滑     → 知情；口；猫在看；视频来电
第5次      罗敏回杭的前一夜               → 她的床；清醒进入；相框；完成式
尾声       罗敏回来，三人对门寒暄         → 钥匙仍在他手里
```

## 四、分章要点

### 第一章｜两扇门

写层楼的静。电梯开门两人同时回家。她抱着画稿，背心领口。他把自己的外卖分她「多点了」。钥匙：她剪了备份，「真的麻烦你，我有时候戴耳机听不见敲门」。他掌心握住那把铜钥匙，像握住器官。

夜。猫眼。她在门厅弯腰捡快递，短裤边。他在自己门后看。不进去。欲望先用合法的看喂饱。

### 第二章｜猫

她去见客户。微信：猫粮在左边柜子，厕所麻烦铲一下，钥匙你有。

他进 1204。第一次独自在她的气味里。尺度：不立刻强奸。打开衣柜，看内衣，闻。在她床上躺下，用她的枕头。偷拍一张空床与相框——裴舟的脸对着他勃起的裤裆。喂猫。猫叫。他走。门关好。她回来只觉得「沈哥好细心，连杯子都洗了」。

他洗了杯子。也打开过她的抽屉。

### 第三章｜饮料

她买了咖啡请他。两人坐她的沙发。罗敏视频打给沈倦，他当着何棠接：「在棠棠家，她请我喝东西。你让我多照顾的。」罗敏在那边笑：「棠棠你监督他，别让他只打游戏。」何棠对镜头挥手。

挂断后他的手落在她膝上。她僵。「沈哥……」他不收回：「罗敏都看见我们坐一起了。你现在把我推出去，她会问为什么突然见外。」

尺度：隔着短裤摸到缝。她夹腿。他停在门口。今晚不进。让她一夜睡不着。让她自己决定明天还要不要这把钥匙。

她没有要回钥匙。

### 第四章｜水管（知情）

夜里她敲 1203：厨房漏水。他关阀，进门，跪在水里修。她也跪着递扳手，背心湿透。

修完。水停了。两个人还跪着。他吻她。她推。他说出抽屉：他知道她内衣的颜色。她傻了。「你翻我东西？」他把手机给她看床照——还没有她本人，但足够证明他来过、躺过。「你要物业？监控只看到我拿着你给我的钥匙进来。合法。」

尺度：口。她跪在自己的厨房地砖上。猫在门口坐着看。裴舟的视频来了。她必须擦嘴接。他在镜头外。裴舟：「地板怎么是湿的？」她：「水管。邻居帮忙。」男友说「帮我谢谢沈哥」。她谢谢。嘴上还有味道。

藏赃：她自己把地擦干，怕物业上来看见两滩水以外的东西。

### 第五章｜相框（完成式）

罗敏明天回杭。最后一夜。他用钥匙开门，她没睡，坐在床上等——不是迎，是知道来了也赶不走，不如醒着。

「钥匙还我。」她说。  
「做完还。」他说。

完成式：

1. 在她自己的床上，裴舟的相框对着他们；  
2. 他让她看着相框进入；  
3. 她求外射，怕床单；他内射，再把相框摆正；  
4. 猫跳上床，她羞到用被子盖住结合处，像怕猫看见；  
5. 做完他真的把钥匙放在她掌心——又从掌心拿走，「再复制一把。罗敏说独居危险。」

她哭着笑了一下，碎的。门对面 1203 开了又关。他回家。洗下身。回罗敏：「水管修好了。你明天几点到。我去接。」

### 第六章｜三人对门

罗敏回来，提了新加坡伴手礼——何棠男友托罗敏公司同事带的（可改成罗敏自己买的点心）。三个人站在两扇门之间寒暄。何棠叫「罗姐」。沈倦的手心里是那把复制的钥匙。

罗敏进 1203。何棠进 1204。门同时关上。猫眼对猫眼。

他发消息：今晚她睡了我就过来。你开门，或者我自己开。

何棠没有回。也没有换锁。

## 五、本线尖在哪

- 空间是**她的主权领土被她亲手交出去**。  
- 第三人是时差里的男友 + 两周后回来的妻子，不是同床。  
- 钥匙比视频更脏：视频是事后锁，钥匙是永久通行证。结局可以不收在车站，收在「她没有换锁」。

# 选用建议

| 若你想要 | 写 |
|---|---|
| 正作续、旧人、把刀插在男友身上 | 《谢珊珊·来接》 |
| 年味、亲属称谓、熟到骨子里的越界 | 《陈书意·守岁》 |
| 全新空间、身体被医嘱锁住、查房作为节拍器 | 《梁秋白·陪床》 |
| 日常更长、没有旅行盒、邻居伦理 | 《何棠·对门》 |

四条都对标《五日》的心理弧线：**不安 → 问一句 → 知情并隐瞒 → 把柄锁死 → 清醒承受 → 带着秘密继续生活**。  
换的只是她不能喊的理由。

## 待你拍板后再动笔的点

1. 先写哪一条。  
2. 《守岁》里陈书意是晓晓亲姐（接入阿凯宇宙），还是独立宇宙换姓名。  
3. 篇幅是否仍七章长篇；《对门》也可改成五章中篇。  
4. 后穴是否在某一条里作为加码（默认四条都不作主线）。

默认项：四条皆可独立成书；《来接》最接《五日》；《陪床》空间最新；《对门》最适合写成日常连载。
