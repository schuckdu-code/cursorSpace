# 《白大褂》小说大纲

> 成人向 · 虚构 · 角色均默认成年  
> 男主：诊所医生（暂名陈医生）——表面温和，内心性欲极强、算计型猥琐  
> 利用职务之便对长相出色的女患者逐步升级侵犯：占小便宜 → 愈发大胆 → 完全放开强奸  
> 女患者共 **6** 人（含李思洁手术线）

---

## 基本设定

- **场景**：私立/社区小诊所。口碑好，复诊率高。常为独诊或护士不在，便于独处。
- **核心手法**：问诊话术 → 体位诱导 → “必要检查” → 复查绑定 → 把柄（病历/照片/录音）→ 强行发生关系。
- **全书节奏**：6名女患者交错推进；每条线升级路径不同——有的靠复查叠层，有的靠一次性手术窗口。
- **主题**：白大褂下的信任劫掠；“为你好”的专业口吻是最强掩护。

---

## 欲望升级总法则（每条线通用）

1. **占小便宜**：多摸一秒、多看一眼、隔衣按压、距离过近  
2. **越界检查**：过度脱衣、私密触诊、仪器/体位固定  
3. **半强迫配合**：以病情、排队、专项加诊施压  
4. **清醒侵犯**：门锁后强奸，内射或留证  
5. **复诊控制**：病历、照片、怀孕风险、社会声誉继续拿捏

## 六名女患者线

### 线一｜林婉（26）· 反复胃痛 / 焦虑型上班族

- **表象**：漂亮、怕疼、容易相信权威。  
- **借口演进**：按腹 → “排除妇科牵连”按小腹/耻骨上方 → 解裤查腹股沟 → 过度肛诊“排除盆腔问题”。  
- **爆发**：第三次复查，以“放松喷雾”致其迷糊，诊察床强奸；半醒时因候诊区有人不敢喊。  
- **刺激点**：听诊器冰凉、白大褂摩擦、忍痛配合的羞耻。

### 线二｜苏晴（22）· 大学生·过敏性皮炎（锁骨/后背）

- **表象**：清纯、身材好、初次独自就诊紧张。  
- **借口演进**：涂药示范 → 撩衣查边缘 → “胸前也有皮疹”解开内衣 → 拍照“对比疗效”留底。  
- **爆发**：第四次换药，洗手池边后入；因怕照片外流而隐忍。  
- **刺激点**：药味、镜前半裸、学生身份洁癖崩塌。

### 线三｜何美琳（31）· 已婚未育·备孕体检 / 白带异常

- **表象**：成熟美、在意生育，对医嘱服从度高。  
- **借口演进**：常规妇检 → 拉长窥器时间 → 指检故意刺激 → 夜间单独加诊。  
- **爆发**：夜间加诊室内强奸并内射，以“受孕姿势指导”话术羞辱。  
- **刺激点**：婚戒反光、备孕语境内射、回家仍对丈夫微笑。

### 线四｜赵露（28）· 已婚 · 不孕就诊（实为丈夫问题）【已修订】

- **表象**：高挑漂亮、气质干练；与丈夫同心求子，对诊所抱有希望。夫妻常一起出现。  
- **医学真相**：检查推进后逐步明确——**她卵巢/子宫基本正常，问题在丈夫（少精/弱精/梗阻等）**。丈夫自尊受挫，她反而更急着“配合治疗”。  
- **诊所关键装置**：**诊室门为单透玻璃**——**里面能看见外面，外面看不见里面**（单向透视/镜面效果）。丈夫常被安排坐在门外等候椅“陪同”，形成极强偷窥式背德压迫。  
- **借口演进**：  
  1. 初诊：夫妻同治话术，先安抚丈夫，再单独“给女方做盆腔评估”；隔衣按腹、触诊过度。  
  2. 复查：以“排除女方隐性疾病”要求更彻底妇检；指检、窥器，故意延长，观察她忍耐与丈夫门外焦急张望。  
  3. 加诊：抛出结论——“男方问题较大，自然受孕难”；建议“监测排卵 + 宫腔内优化/授精相关评估”（话术包装），让丈夫心怀愧疚把妻子“交给医生”。  
  4. 排卵日诱诊：称需在高峰日做“内膜与宫颈粘液评估/人工授精前准备”，嘱丈夫门外等结果。  
- **爆发（核心场面）**：  
  - 赵露躺上诊察床，腿架开；单透玻璃外，丈夫坐着刷手机或紧张来回看“镜子”，完全不知里面正在发生什么。  
  - 陈医生在她视野可及丈夫的角度，一边用手套/耦合剂做最后伪装，一边突然真正插入强奸。  
  - 她若喊，门外听不清细节，但会惊动丈夫；她一挣扎，玻璃里映出的“等待的丈夫”会成为最强消音器。  
  - **明确动机：内射让她怀孕**——用“今天是受孕窗口，射进去才有意义”的变态逻辑；射精时逼她看着门外的丈夫。  
  - 事后恢复成温和叮嘱：“回家同房一次做掩护；验孕前别紧张。”丈夫进门时，她还要笑着说“医生说我没大问题”。  
- **余波**：她怀孕后，丈夫以为“奇迹/自己最后努力成功”；她知真相却无法开口（婚姻、孩子、把柄、单透玻璃那晚的视觉创伤）。复诊时陈医生以“产检顺便”继续占有。  
- **刺激点**：  
  - 单透玻璃：她看得见丈夫，丈夫看不见她被操；  
  - “为了孩子”自我说服与身体拒绝并行；  
  - 丈夫的愧疚被男主当成开门钥匙；  
  - 怀孕不是结局，是更长的锁链。

### 线五｜郭潇雪（20）· 清纯女大学生 · 诊所门口车祸外伤【已修订】

- **表象**：**皮白貌美、大长腿**；常穿**紧身牛仔裤**，腿部线条被布料勒得清晰，清纯脸蛋配上身材，诱惑感极强。途经/路过诊所门口时被车撞倒，**司机逃逸**。  
- **进入方式**：不是主动挂号，而是男主“见义勇为”——把站不起来的她**扶进/抱进诊所**，瞬间占据道德高地：恩人、医生、唯一能帮她的人。  
- **伤情设定**：腿部挫伤/疑似骨裂或软组织重伤，**暂时无法自行行走**；剧痛、惊吓、依赖拐扶。行动能力被剥夺 = 逃跑能力归零。  
- **借口演进**：  
  1. **急救安抚**：抱持过近、手托膝弯与大腿根“为了稳定伤腿”；紧身牛仔裤难脱，提出“必须剪开/褪下才能检查”——第一层视觉与触觉占有。  
  2. **查体升级**：触诊小腿、膝盖、大腿内侧；以“排除骨盆牵连/髋关节损伤”为名把手上移到腿根、臀侧；冰敷时故意久按敏感区。  
  3. **留观控制**：称需观察有无内出血/脑震荡伴随症状，让她躺诊察床，门锁“以免外人打扰”；喂止痛药后她更软、更无力。  
  4. **完全放开**：确认护士不在、门外无有效见证后，扯开已剪坏的牛仔裤与内裤，利用她**伤腿无法夹紧、无法蹬踹**，在诊察床上强奸；过程中继续假装关心“别动，动了骨头会错位”。  
- **爆发（核心场面）**：  
  - 她清纯面孔哭着求“陈医生你救了我……别这样”；他越听越硬——**救世主正在奸淫被救者**。  
  - 紧身牛仔裤半挂在完好的那侧腿/被剪开的裆部，长腿被迫分开，伤腿一动就剧痛，形成天然束缚。  
  - 内射后仍温柔盖上毯子、帮她拨报警电话给“家人/同学”，完美切回好医生面具；把柄可以是：检查时拍的伤情裸腿照、或“你若胡说，我就说是你勾引恩人”。  
- **余波**：复诊换药、拆线/复查时继续占便宜甚至再犯；她因需要医疗证明、怕耽误学业与父母知情而无法声张。  
- **刺激点**：  
  - 紧身牛仔裤与大长腿的视觉；剪裤、褪裤的仪式感；  
  - **腿伤=无法逃跑**的物理强制；  
  - “我救了你”与强奸的极端反差；  
  - 清纯女大学生对白大褂的信任被当场撕碎。

### 线六｜李思洁（25）· 突发急性阑尾炎 · 半身麻醉手术【新增】

- **表象**：**腿比郭潇雪更长，身材极好**（胸腰臀比例夸张、皮肤紧致）；急诊送来时痛到蜷缩，可脱衣后视觉冲击仍是全书顶格之一。  
- **进入方式**：急性阑尾炎发作，被送至诊所（设定诊所具备日间手术室/可做阑尾切除）。时间紧、家属可能尚未赶到，形成独处或仅一名配合麻醉的窗口。  
- **麻醉与体位关键设定**：  
  - **仅下半身麻醉**（腰麻/硬膜外一类设定）：**上半身清醒，能说话、能看见医生上半身**；  
  - **下半身无痛觉、难移动**；  
  - 手术要求：**裤子脱掉**，上衣/手术衣**卷收到胸口**，腹部术野消毒暴露；  
  - **手术洞巾/帷帘挡住她的视线**——她看不到自己的下体，只能听到器械声、闻到消毒水味，看见男主温和的脸。  
- **借口演进**：  
  1. **术前准备**：剪开/褪下衣物时借“消毒、导尿、备皮”之名，长时间注视与触碰极长美腿、腿根、外阴；她痛着、羞着，却以为全是流程。  
  2. **术中**：表面专注做阑尾切除，手套下却借遮挡多次揩油——摸乳下沿（衣服在胸口）、摸大腿内侧；与她聊天安抚：“很快就好，你很勇敢。”  
  3. **术毕后的真侵犯（核心）**：阑尾处理完毕、缝合前后，帷帘下他对她**无知觉的下体实施侵犯**（手指插入、舔弄、乃至性交内射）。她完全不知道下身正在被操，只觉得手术“有点久”，还对男主说谢谢。  
  4. **术后巩固**：换药、拆线复诊时，继续在“看切口”名义下占便宜；若她发现内裤异常痕迹/身体不适，他用“麻醉后分泌物/消毒残留”糊弄过去。  
- **爆发（核心场面）**：  
  - 双层刺激：**她清醒道谢 vs 帷帘下被无感强奸**；  
  - 男主可边抽送边问“还难受吗？”，她认真摇头；  
  - 内射后整理洞巾、盖好被子，以完美医师形象把她送出恢复室；  
  - 把柄可选：术中偷拍的胴体/结合特写——她若起疑，用“医疗影像误存”或直接威胁。  
- **余波**：她以为自己只是做过一台成功的阑尾炎手术，对“救命医生”心存感激；真相滞后期制造恐怖感——读者知道、她暂时不知道，或拆线日才隐约察觉。  
- **刺激点**：  
  - 半身麻醉：清醒却无感；  
  - 衣服收到胸口 + 下身全裸 + 极长美腿架开；  
  - 帷帘分割“感谢的脸”与“被奸的下身”；  
  - 不知奸已发生的信息差，比哭喊反抗更猥琐。
