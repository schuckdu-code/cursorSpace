# 《白大褂》小说大纲

> 成人向 · 虚构 · 角色均默认成年  
> 男主：诊所医生（暂名陈医生）——表面温和，内心性欲极强、算计型猥琐  
> 利用职务之便对长相出色的女患者逐步升级侵犯：占小便宜 → 愈发大胆 → 完全放开强奸

---

## 基本设定

- **场景**：私立/社区小诊所。口碑好，复诊率高。常为独诊或护士不在，便于独处。
- **核心手法**：问诊话术 → 体位诱导 → “必要检查” → 复查绑定 → 把柄（病历/照片/录音）→ 强行发生关系。
- **全书节奏**：5名女患者交错推进；每条线都走完整升级，但借口、气质、崩溃点不同。
- **主题**：白大褂下的信任劫掠；“为你好”的专业口吻是最强掩护。

---

## 欲望升级总法则（每条线通用）

1. **占小便宜**：多摸一秒、多看一眼、隔衣按压、距离过近  
2. **越界检查**：过度脱衣、私密触诊、仪器/体位固定  
3. **半强迫配合**：以病情、排队、专项加诊施压  
4. **清醒侵犯**：门锁后强奸，内射或留证  
5. **复诊控制**：病历、照片、怀孕风险、社会声誉继续拿捏

## 五名女患者线

### 线一｜林婉（26）· 反复胃痛 / 焦虑型上班族

- **表象**：漂亮、怕疼、容易相信权威。  
- **借口演进**：按腹 → “排除妇科牵连”按小腹/耻骨上方 → 解裤查腹股沟 → 过度肛诊“排除盆腔问题”。  
- **爆发**：第三次复查，以“放松喷雾”致其迷糊，诊察床强奸；半醒时因候诊区有人不敢喊。  
- **刺激点**：听诊器冰凉、白大褂摩擦、忍痛配合的羞耻。

### 线二｜苏晴（22）· 大学生·过敏性皮炎（锁骨/后背）

- **表象**：清纯、身材好、初次独自就诊紧张。  
- **借口演进**：涂药示范 → 撩衣查边缘 → “胸前也有皮疹”解开内衣 → 拍照“对比疗效”留底。  
- **爆发**：第四次换药，洗手池边后入；因怕照片外流而隐忍。  
- **刺激点**：药味、镜前半裸、学生身份洁癖崩塌。

### 线三｜何美琳（31）· 已婚未育·备孕体检 / 白带异常

- **表象**：成熟美、在意生育，对医嘱服从度高。  
- **借口演进**：常规妇检 → 拉长窥器时间 → 指检故意刺激 → 夜间单独加诊。  
- **爆发**：夜间加诊室内强奸并内射，以“受孕姿势指导”话术羞辱。  
- **刺激点**：婚戒反光、备孕语境内射、回家仍对丈夫微笑。

### 线四｜赵露（28）· 已婚 · 不孕就诊（实为丈夫问题）【已修订】

- **表象**：高挑漂亮、气质干练；与丈夫同心求子，对诊所抱有希望。夫妻常一起出现。  
- **医学真相**：检查推进后逐步明确——**她卵巢/子宫基本正常，问题在丈夫（少精/弱精/梗阻等）**。丈夫自尊受挫，她反而更急着“配合治疗”。  
- **诊所关键装置**：**诊室门为单透玻璃**——**里面能看见外面，外面看不见里面**（单向透视/镜面效果）。丈夫常被安排坐在门外等候椅“陪同”，形成极强偷窥式背德压迫。  
- **借口演进**：  
  1. 初诊：夫妻同治话术，先安抚丈夫，再单独“给女方做盆腔评估”；隔衣按腹、触诊过度。  
  2. 复查：以“排除女方隐性疾病”要求更彻底妇检；指检、窥器，故意延长，观察她忍耐与丈夫门外焦急张望。  
  3. 加诊：抛出结论——“男方问题较大，自然受孕难”；建议“监测排卵 + 宫腔内优化/授精相关评估”（话术包装），让丈夫心怀愧疚把妻子“交给医生”。  
  4. 排卵日诱诊：称需在高峰日做“内膜与宫颈粘液评估/人工授精前准备”，嘱丈夫门外等结果。  
- **爆发（核心场面）**：  
  - 赵露躺上诊察床，腿架开；单透玻璃外，丈夫坐着刷手机或紧张来回看“镜子”，完全不知里面正在发生什么。  
  - 陈医生在她视野可及丈夫的角度，一边用手套/耦合剂做最后伪装，一边突然真正插入强奸。  
  - 她若喊，门外听不清细节，但会惊动丈夫；她一挣扎，玻璃里映出的“等待的丈夫”会成为最强消音器。  
  - **明确动机：内射让她怀孕**——用“今天是受孕窗口，射进去才有意义”的变态逻辑；射精时逼她看着门外的丈夫。  
  - 事后恢复成温和叮嘱：“回家同房一次做掩护；验孕前别紧张。”丈夫进门时，她还要笑着说“医生说我没大问题”。  
- **余波**：她怀孕后，丈夫以为“奇迹/自己最后努力成功”；她知真相却无法开口（婚姻、孩子、把柄、单透玻璃那晚的视觉创伤）。复诊时陈医生以“产检顺便”继续占有。  
- **刺激点**：  
  - 单透玻璃：她看得见丈夫，丈夫看不见她被操；  
  - “为了孩子”自我说服与身体拒绝并行；  
  - 丈夫的愧疚被男主当成开门钥匙；  
  - 怀孕不是结局，是更长的锁链。

### 线五｜周宁（24）· 圈内人介绍·急性尿路感染

- **表象**：极美、略懂医疗，最难骗，最激发征服欲。  
- **借口演进**：导尿“示范” → 膀胱区按压 → “取样失败”反复插管 → 痛与安抚交替，建立创伤依赖。  
- **爆发**：识破欲报警；锁门诊室长时间强奸；事后仍开正规处方，面具瞬间切回。  
- **刺激点**：懂行者崩溃；术语与脏话并置；惯犯式从容。
