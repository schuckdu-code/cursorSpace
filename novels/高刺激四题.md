# 高刺激四题

人物各自独立。视角男主第一人称。尺度全露骨，往不可逆、当众、把第三人碾碎里写。  
只写大纲，不写正文。不写可照做的侵入与制伏步骤。

这四条的刺激不靠「差点被发现」，靠三件事同时成立：

1. 她必须当众把脸维持住；  
2. 丈夫必须亲手参与自己被戴绿帽；  
3. 留下她带不走的东西：精液、孕、亲戚的眼睛、会议录音。

# 一｜《姜寻·掰开》

丈夫不是观众。丈夫是道具。他要亲手把妻子的腿掰开，数到进去，再把精液舔干净。目标写明：内射到她不敢吃避孕药。

## 人物

| 角色 | 设定 |
|---|---|
| **魏晏** | 男主。33 岁。卢白的新上司。家访「谈加班」进门。 |
| **姜寻** | 女主。26 岁。刚结婚半年。瘦，胸小而挺，居家只穿卢白的T恤，下摆遮不住臀。怕丢脸比怕疼更甚。 |
| **卢白** | 丈夫。29 岁。怕丢工作。威胁点不是刀，是明天的绩效和今晚的录像。 |

- 地点：他们自己的婚房。一夜。  
- 把柄：卢白的脸必须入镜——他的手在掰她的膝。这段不像强奸，像丈夫同意的换妻。

## 刺激点（必须写进正文）

- 魏晏让卢白自己说：「哥，我老婆给你操。」说不利索就加重。说完，姜寻才被允许开始。  
- 口的时候卢白按住妻子后脑，因为「你会咬」。射进喉咙，检查，让卢白看舌面。  
- 进入前卢白双手掰开她的腿，报数。姜寻看天花板，魏晏命令她看卢白。龟头抵着穴口时要卢白说「进」。  
- 内射两次。第一次在婚床，第二次在他们还没拆封的孕妇枕头上——姜寻买来是玩笑，今晚拿来垫腰。  
- 逼她把避孕药倒进马桶。卢白按冲水。  
- 事后清理：卢白被命令舔走溢出来的精。姜寻哭着按他的头。三个人的婚姻从这一下开始臭。  
- 天亮前视频给姜寻母亲问安。镜头只切锁骨以上。她说「卢白对我很好」。魏晏还埋在里面，小幅度顶，让她声线发飘。母亲说「你是不是感冒」。

## 章法

1. 家访，门关，控制卢白（只写结果）。  
2. 逼开口那句「给你操」。手、口、检查舌面。  
3. 掰膝、报数、第一次内射。孕妇枕。  
4. 倒药、第二次、逼丈夫舔。  
5. 给母亲视频。出门。走廊遇见邻居，姜寻必须叫「魏哥，慢走」。腿间还在漏。

收束：卢白跪在浴室吐。姜寻坐在马桶盖上，手里是空的药板。她没有去药店。

# 二｜《祝宁枝·倒茶》

亲友在客厅。她是女主人。体内含着精，穴里塞着还在震的东西，内裤是丈夫的，已经被淫水浸透。她要笑，要添茶，要叫妈。

## 人物

| 角色 | 设定 |
|---|---|
| **沈咎** | 男主。35 岁。程礼大学同学，以「路过」留下吃午饭。 |
| **祝宁枝** | 女主。29 岁。会持家，胸臀都沉，围裙勒出腰。最见不得在长辈面前失态。 |
| **程礼** | 丈夫。被限制在主卧衣帽间。门留一条缝，听得见客厅每一句「妈，您慢用」。 |
| **程母** | 来客。五十五岁。话多，要看新窗帘、要进主卧找旧相册。 |

- 地点：两室，周六午宴到黄昏。  
- 把柄：程母随手拍的「家庭聚餐」。背景里宁枝耳根红、坐姿别扭。放大能看见围裙下摆湿了一点。

## 刺激点（必须写进正文）

- 客人进门前十分钟，沈咎在厨房从后面进她，内射，用跳蛋顶回去，外沿用她自己的内裤堵住。命令：午饭结束前不许漏到地板上。  
- 倒茶时震档被他手机遥控。她手抖，茶洒在程母手背。她鞠躬道歉，弯腰时穴里那东西顶到最深，她当众「嗯」了一声，改口成「烫」。  
- 程母要进主卧拿相册。衣帽间里是程礼。宁枝必须自己拦：「妈，里面乱。」拦的代价是沈咎在桌下伸手进围裙，当众按阴蒂。程母还在说话。  
- 饭后水果。沈咎让她去卫生间「整理」。其实是把她按在洗手台补射一次，精液灌满到小腹发胀，再把跳蛋塞回去。她要在三分钟内擦嘴、补口红、回桌。  
- 程母终于要走。送电梯。沈咎跟出去「送阿姨」。门一关，他在电梯镜里用手帕擦宁枝眼角，像关心。程母夸「小沈真会疼人，礼儿你要学」。程礼的声音从卧室缝里出不来。  
- 客人走光。完成式不在床上：在门垫上，对着猫眼。她跪趴，脸朝门外，沈咎整根进去把跳蛋顶到最深再拉出来，带出混浊。程礼被拖到门口看自己妻子的穴往外吐精。内射第三次。她求「别在门这儿，对门会回来」。他偏要。

## 章法

1. 厨房先灌满。塞。门铃响。  
2. 午宴，遥控，洒茶，拦卧室。  
3. 卫生间补射。三分钟化妆。  
4. 送电梯。  
5. 门垫、猫眼、丈夫当面看吐精。

收束：碗还在桌上。程母微信：宁枝今天怎么不太舒服，是不是有了。宁枝看着对话框，穴里还在往外淌。她不知道回什么。

# 三｜《严澄·全员开麦》

会议录了音。她是主讲。摄像头按规定要开。画面裁到锁骨。锁骨以下，上司整根埋着，囊袋拍她的臀，声音被她用「嗯、这个数据」盖掉。

## 人物

| 角色 | 设定 |
|---|---|
| **祁深** | 男主。36 岁。她的直属总监。有权让她「留会议室复盘」。 |
| **严澄** | 女主。28 岁。业务骨干。声音冷静，脸漂亮，开会从不露肩。今天被命令穿低领「显得亲和」。 |
| **严澄丈夫·佟牧** | 在出差，被拉进会议当「客户代表旁听」。他听得见妻子的气口，看不见她坐在谁身上。 |

- 地点：玻璃会议室，百叶帘拉上。门外是工位。一夜不够，这场会是四十分钟，会后还有打扫。  
- 把柄：公司云录播。官方是「严澄Q3分享」。私剪是她每次被顶到的吸气。两份文件同一时间码。

## 刺激点（必须写进正文）

- 会前他已经在她体内。她穿着职业裙，不穿内裤，精液是上一轮的润滑。坐下去时整根吃到最底，她对着镜头说「各位好」。  
- 佟牧出现在参会列表。她瞳孔一缩。祁深耳语：「跟你老公问好。」她说：「牧哥也在，今晚我早点收。」佟牧打字：加油。  
- 她翻页时被顶。数字念错。祁深在聊天框公屏：严澄再确认一下第三页。全员看见。她道歉，穴把人绞紧。  
- 有人提问。她必须答。祁深专往那一点磨，逼她在「同比上升百分之十二」里把高潮咬碎。她高潮时摄像头还开着，只是下巴抬了一下。总监说「不错，继续」。  
- 射精发生在她总结的最后一句。内射。精液量大，她夹着念「以上就是我的部分」。下线。  
- 会后门外有人敲门要借用会议室。她必须站起来开门——精液沿大腿内侧往下滑。她把文件袋挡在小腹。同事进来，夸「你今天声音好软」。祁深坐在原位整理皮带。  
- 晚上佟牧视频：「你是不是紧张，气声好重。」她说空调。祁深从镜头外走进浴室，按着她后颈，在视频还没挂时从后面再进一次。佟牧问「你旁边有人吗」。她说没有。水声开到最大。

## 章法

1. 会前进入、坐实。  
2. 全员、丈夫入会、问好。  
3. 提问、高潮、总结内射。  
4. 同事借会议室，精液下滑。  
5. 夜里视频，挂断前再来一次。

收束：录播链接发到全群。她点开，听见自己那句「百分之十二」里有一声极短的湿响。没有人评论。链接不会失效。

# 四｜《乐晚宁·工位》

白天。丈夫的公司。她来送文件。体内是别人的精。电梯、前台、工位隔板，全是眼睛。高潮发生在丈夫起身去打印的九十秒。

## 人物

| 角色 | 设定 |
|---|---|
| **霍不周** | 男主。31 岁。丈夫的同事，工位在斜对面。以「我下楼接你嫂子」把她截在电梯。 |
| **乐晚宁** | 女主。27 岁。穿丈夫喜欢的白裙子来送周年旅行的护照。裙子薄，精斑在日光下会显形，所以她必须夹紧。 |
| **卞成** | 晚宁丈夫。热情，要介绍同事。会拉她到霍不周桌边：「这是不周，平时我加班都他帮忙。」 |

- 地点：写字楼十二层。下午四点到五点半。  
- 把柄：工位显示器的摄像头被霍不周打开「调试」。录到的是桌下她的膝和白裙掀起的一角，以及卞成的声音在画面外喊「咖啡要吗」。

## 刺激点（必须写进正文）

- 电梯里先口。监控对着脚。她蹲在镜头死角，霍不周按开门键延迟。射在嘴里。她必须咽，因为出电梯要笑。精液没咽干净，嘴角一点，他用拇指抹进她唇里。前台叫「卞成妻子来了」。她应「是」。  
- 到工位。卞成拥抱她。手贴在她臀上时，臀缝里还湿。霍不周伸手：「嫂子，护照我帮你复印。」接过文件，指节擦过她掌心——掌心刚才撑过地。  
- 卞成去打印。九十秒。霍不周把她拉到工位下，白裙翻到腰，已经含过一次的穴直接坐上。她面对通道。有人走过。她把脸埋进他椅背。他内射。卞成的声音靠近：「不周，我哥那份也打了。」她必须在抽出后三秒内把裙摆放下，站起来。精液开始往下走。  
- 卞成回来，请她坐自己椅子。椅子还热。她坐下，精液被坐回去。三人聊天。霍不周问：「嫂子脸红什么。」卞成笑：「害羞。」晚宁说：「电梯闷。」  
- 去卫生间。霍不周跟进去。隔间。从后面进，补射，把溢出来的刮回去。门外有女同事说话。她咬自己手腕。  
- 离开时卞成送她到闸机。霍不周也来。过闸机要侧身。裙摆被风掀起一瞬。卞成没看见。闸机摄像头看见了腿根一点亮。霍不周后来说会「帮忙申请删除」。删除键在他手里。

## 章法

1. 电梯口、咽精、见前台。  
2. 拥抱、交护照。  
3. 打印九十秒、工位下内射、坐回丈夫的椅子。  
4. 女厕隔间补射。  
5. 闸机。风。

收束：晚宁上出租车。司机问去哪。她报了家。座位湿。她把护照抱在小腹上，封面压着还在跳的肚皮。卞成短信：不周说你人真好。她删掉，又恢复。不敢把对话留白。

# 四条分别碾的是什么

| 题目 | 碾碎的东西 |
|---|---|
| 《掰开》 | 丈夫的手和嘴，避孕药，母亲视频 |
| 《倒茶》 | 婆婆的眼睛，女主人的脸，门垫与猫眼 |
| 《全员开麦》 | 全公司录播，丈夫当旁听客户，高潮当数据 |
| 《工位》 | 白天、日光、丈夫的椅子、九十秒 |

若还要更狠，只能再往上加一层「当场被不该看的人看清」——例如程母推开主卧、佟牧要求开摄像头、卞成提前回来。那一层默认作章末炸弹，不提前用光。

先定一条开写。
