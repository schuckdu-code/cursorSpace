# 刘婵

> 视角：男主第一人称  
> 地点：杭州  
> 尺度：全露骨  
> 人物：女主刘婵（成年）；其男友陈屿；男主为滨江某互联网公司程序员（叙述者）

杭州程序员。朋友局里遇见刘婵——别人的女朋友，清淡、话少，看得懂他的欲望，却不给。几次快碰到，都被她亲手掐断。先只许口和手，再让进、不准射里面。第八章他没退出去。第九章起变成强奸，再慢慢凌辱、调教成性奴。她仍可以做陈屿的女朋友。
