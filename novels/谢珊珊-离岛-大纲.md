# 《谢珊珊·离岛》构思大纲

> 人物关系完全沿用《谢珊珊·五日》，剧情、场景、推进手段全部重写。  
> 本文只提供大纲，不写正文。

---

## 一、不变项

| 角色 | 关系 |
|---|---|
| 谢珊珊 | 女主。来散心，与男友阿杰处于冷战/暂别。称男主「阿凯哥」。 |
| 晓晓 | 珊珊闺蜜，男主妻子。全程信任两人，不知情。 |
| 阿凯 | 男主，第一人称。晓晓丈夫。对珊珊起意，逐步侵占。 |
| 阿杰 | 珊珊男友。只在对话、回忆、梦呓里出现，本人不到场。 |

- 视角：男主第一人称  
- 尺度：全露骨（与原作同级）  
- 时间跨度：仍是五日，但五日里发生的事全部换掉  
- 心理弧线保留：怀疑 → 知情并隐瞒 → 被把柄锁死 → 清醒承受 → 带着秘密离开  
- 晓晓始终是「在场的墙」：近到能听见呼吸，远到看不见真相

---

## 二、重构原则（相对原作）

原作核心场景全部废弃，不沿用、不改装：

- 不用上海一室一厅、电车过夜、虹桥接站  
- 不用迪士尼、电影院中间座  
- 不用助眠饮料/迷药  
- 不用地下停车场对质  
- 不用卧室地铺  
- 不用 KTV 包厢厕所  

新作改用另一套封闭系统：

- **地理封闭**：离岛。船班有限，信号不稳，台风可随时封航。  
- **空间封闭**：包下一栋临海两层民宿，不是挤一间房。  
- **把柄机制改写**：不用「迷奸录像」开局。先用「可被解释成偷情的照片 + 嫁祸口吻」锁嘴，再补关键影像。  
- **天气当帮凶**：潮汐、海风、暴雨、停电，替代乐园黑暗与影院音响。  
- **晓晓的缺席方式改写**：不是洗澡/看电影睡着，而是拍照走神、村里喝酒、独自去祈福、怕玻璃碎躲进无窗杂物间。

---

## 三、新设定

**地点**：东海某离岛（可虚构成「青屿」）。只有一班早船、一班午船。岛上一家超市、一座灯塔、一处潮间带、一家小酒馆。

**由头**：晓晓订了结婚纪念日五日游，同时把刚跟阿杰闹翻的珊珊拉来「透气」。阿凯负责开车到码头、搬行李、当司机和「可靠的姐夫」。

**住宿**：民宿「听潮」。他们包栋。

- 一楼：客厅、厨房、主卧（晓晓与阿凯）  
- 二楼阁楼：珊珊的客房。有天窗、面海窗、木梯，空间窄，风一大窗子会响  
- 屋侧：冲沙用的户外花洒  
- 天台：晾衣、看海

**阿凯的位置**：不再睡车里。他合法地睡主卧，非法地爬阁楼。空间上更「像一家人」，心理上更背德——他不是被挤出去的外人，而是这栋房子的男主人。

**欲望对象的新意象**：盐、湿衣服贴身、晒痕与没被晒到的白、木头楼梯的吱呀、潮声盖住喘息。珊珊的身体不再用「短裙 + 沙发」为主，而用「被海风灌透的裙子、泳装勒痕、事后的沙和盐」。

## 四、五日总线

```
第一日  渡轮 / 阁楼窗     → 占便宜，她似醒非醒
第二日  潮间带 / 户外花洒 → 白天越界，她开始问
第三日  灯塔 / 酒馆夜     → 她知情，第一次被迫动手，差点被晓晓撞破
第四日  空屋 / 早归       → 清醒开苞 + 照片把柄，投降词出现
第五日  封航 / 台风停电   → 醒着被完整侵占；开航日扇耳光离开
```

把柄升级路径（替代原作「口 → 手 → 迷奸录像 → 地铺 → KTV」）：

1. 第一夜：她不敢确定阁楼里的人是不是阿凯  
2. 第二日：她问了，但怕晓晓听见，问完就缩回去  
3. 第三夜：她第一次在清醒中被强迫参与，选择不喊  
4. 第四日：空屋里被真正进入；他留下「看起来像偷情」的照片（她睁眼、她抓床单、她穿着晓晓的纪念日睡裙）——比迷奸录像更难解释  
5. 第五日：台风把船封死，她逃不走；停电夜把最后一层也撕开  
6. 回航：影像不删。岛会离开，把柄不会

## 五、分章大纲

全书七章，覆盖五日。章名均为新的，事件均不复用原作。

### 第一章｜渡轮上的盐（第一日·抵达）

**日间**

- 开篇不在车站，在甲板。海风把珊珊的裙子贴在腿上，她抓着栏杆干呕（轻微晕船），晓晓给她喂糖，阿凯从身后接过她的包，胸膛贴上她的背——第一次身体接触有正当理由：怕她栽进海里。  
- 下船后是电瓶车，不是私家电车。山路颠，她坐后座侧边，阿凯的手「扶车」时反复擦到她腰。  
- 听潮民宿：晓晓兴奋地选主卧（能看日出）；阁楼给珊珊「清静」。阿凯送行李上楼，阁楼矮，两人必须弯腰。他帮她开卡死的窗，身体越过她，手覆在她手上一起推窗框。窗开的瞬间海风灌入，她的领口被吹开。他看了一眼，没有立刻动手。

**夜间**

- 天台晾泳装。晓晓在楼下热姜茶。风掀起珊珊的T恤，他「帮她按住」，掌心停在肋下太久。  
- 三人晚饭。晓晓说纪念日，珊珊说阿杰最近总熬夜不回消息。阿凯接话：「在这儿谁也找不到你。」这句话她听成安慰，他心里当许可证。  
- 夜里海风把阁楼窗拍响。晓晓睡死。阿凯借口「窗子又卡了」上楼。珊珊睡着，一条腿露出被外，泳装勒痕还印在大腿根。  
- 他不插、不入口。只做开胃：看、闻、用手隔着内裤确认形状，用勃起的前端贴她嘴唇感受呼吸。窗框再次拍响时她哼了一声，睫毛动了。  
- 他退到梯子口，假装刚上来。她迷迷糊糊问「谁」。他说「修窗。风太大。」她说「……哦。」没有叫晓晓。  
- 章末：他回到主卧，躺在晓晓身边，手上还有盐和她腿根的味道。五日从一扇会响的窗子开始。

**本章功能**：建立新空间、新气味、新借口。她的第一道缝是「阁楼的窗」，不是「半夜上厕所」。

---

### 第二章｜退潮之后（第二日·白天越界）

**日间：潮间带**

- 晓晓拍照上瘾，追着寄居蟹往礁石深处走，把两人抛在浅水区。  
- 一个回头浪把珊珊打倒。阿凯「救人」：手从腋下捞，掌心结结实实兜住胸；另一条腿跪进她两腿之间，防她再被卷走。浪退之后他没有立刻起来，湿裤子顶着她小腹。  
- 她推他，他说「礁石滑」。晓晓远远喊「拍到了！你们好有爱」——镜头对准他们时，他才松开。这张「有爱」的照片，后面会变成把柄的第一块砖。

**下午：透明皮划艇**

- 三人租艇。晓晓坐头、珊珊居中、阿凯在后。晓晓一直低头看水下鱼。  
- 他的手从她身后伸进救生衣空隙，沿腰侧滑到泳装裤沿，在水下摸。桨声、浪声、晓晓的惊叹声把她的抽气盖住。她夹桨的膝盖发抖，却不能大叫——一叫，晓晓回头就看见姿势。

**傍晚：户外花洒**

- 民宿规矩：下海必须先冲沙，才能进门。晓晓进厨房煮海鲜。珊珊在屋侧花洒下冲。  
- 阿凯「送毛巾」绕过去。隔着一层水雾看她：泳衣已经褪到腰，背对院子，肩胛和腰窝有沙。他走进去，把毛巾挂上钩，人没有退。  
- 第一次清醒的近距离对峙。她问：「昨晚阁楼，是你？」  
- 他不否认也不承认，只说：「窗是我修的。你要是跟晓晓说有人碰你，她先问你为什么不当时喊。」  
- 她抓住了重点：不是「他做了什么」，是「我为什么当时不喊」。羞耻开始替他工作。  
- 他用手背擦掉她锁骨上的沙，再往下，停在胸口。水还在淋。她抓住他手腕，力道不够。厨房里晓晓喊「谁吃辣的」。他松开，把毛巾塞她手里，先回去。

**夜间（本章收束，不做到底）**

- 珊珊洗澡后把自己锁在阁楼。锁是老式的，从外面能拨开。  
- 他进来时她醒着，背贴墙。他用手、用腿，逼她把声音咽回去——楼下晓晓在跟妈妈视频通话，笑声清清楚楚传上木梯。  
- 本章最高尺度：清醒状态下的口，浅，短，被楼下视频笑声打断。他射在她锁骨，用花洒那条毛巾擦掉。  
- 离开前说：「你看，你又没喊。」

**本章功能**：从「不确定」推进到「问了一句又缩回去」。把柄还不是影像，是她自己的沉默。

---

### 第三章｜灯塔路（第三日·知情并动手）

**日间：骑行去灯塔**

- 租自行车。晓晓为了拍黄金时刻冲在前面，把两人甩开一个弯。  
- 灯塔背面是断崖和小径，监控拍不到，游客很少。他把珊珊按在晒热的白墙上，裙子掀起来，手指进去。海风很大，她的骂和哭都被风撕碎。  
- 晓晓在塔顶喊「你们快上来看日落」。他抽手，把她的裙子放下，先走。她必须自己整理好，再出现在闺蜜面前。  
- 日落合影：晓晓搂她，她笑得很差。阿凯拍下这张——后面会和墙根那几张连着给她看。

**夜间：岛上唯一的酒馆**

- 晓晓跟老板娘聊开，喝了两杯米酒，非要再唱两首。珊珊想先回，晓晓说「阿凯送她，我马上就来」。  
- 回程山路黑。他没有在路上做，让她以为逃过一晚——进阁楼后才关门。  
- 尺度：逼她用手。理由新做：木梯太响，他自己动衣服会响，必须她动手。她哭着问「你到底要怎样」，开始出现「求」。  
- 关键差点穿帮：她手上还黏着的时候，院子里传来晓晓的笑声和脚步。她吓到整个人僵住。阿凯把她按进被窝，自己下到一楼去「接老婆」，若无其事帮晓晓脱鞋。珊珊在阁楼里听他们接吻、说「珊珊睡了吧」，把精液擦进自己的衣服里。

**本章功能**：她从「受害者」滑向「必须自己藏赃」的人。原作影院纸巾团的心理，改在阁楼+楼下脚步里完成。

---

### 第四章｜空屋（第四日·白天开苞）

**制造空窗的新方法（不用装病、不用迷药）**

- 阿凯提前以纪念日名义，给晓晓报了岛上寺庙的「姻缘祈福 + 集市采买」半日行程。晓晓高兴得要命，觉得丈夫懂浪漫。  
- 珊珊想跟着去，晓晓说「你晒伤了待着，我带特产回来」。珊珊失去唯一的人墙。

**空屋里**

- 她把自己反锁在阁楼。他用前台备用钥匙（包栋时前台给过全套）。  
- 她醒着、抗拒、骂他畜生。他不打她，只用两件事压她：  
  1. 晓晓此刻正在庙里为这段婚姻祈福；  
  2. 若她跑出去喊，岛上全是熟人，第一句话会变成「你闺蜜丈夫强奸你？那你前两天为什么不说？」  
- 尺度：清醒破处。不用沉睡。痛、血、她喊阿杰的名字。他纠正：不是阿杰，是阿凯哥。  
- 他拍照的策略与原作相反：不只拍器官，更拍「她睁着眼、咬着自己的手、身上穿着晓晓为纪念日买的丝绸睡裙」（那件裙子晓晓早上试过，随手搭在沙发上）。这组照片的杀伤力是：看起来像偷情，不像迷奸。她越看越没法报警。

**早归**

- 晓晓电话：集市遇到顺风三轮，提前回来。  
- 他只来得及做最低限度的清理。珊珊必须假装午睡中暑。晓晓进门就心疼，煮绿豆汤、敷毛巾，手按在她刚被内射过的小腹上问「是不是经期要来了」。  
- 珊珊当着晓晓的面说「可能是」。这句话是新的投降。

**傍晚天台**

- 晓晓洗澡。他在天台把照片划给珊珊看。海风很大，她站不稳。  
- 他的条件改写：不是「我感冒了打地铺」，而是「今晚起你别锁阁楼。船还没开。你想闹，这些照片先到晓晓手机上——她会看见你穿着她的睡裙。」  
- 她的投降词：「别给晓晓看。」

**本章功能**：开苞从「沉睡的缝」改为「空屋里的清醒」。把柄从「犯罪录像」改为「像出轨的证据」。道德绞索更紧：她怕的不只是被奸的事实，是闺蜜会相信她是第三者。

---

### 第五章｜封航通知（第四日夜 → 第五日白天）

**转折**

- 晚饭时广播/短信：台风靠近，明日船班取消。五日被迫延长。晓晓欢呼「赚到一天」。珊珊脸色灰白——逃生日被天气没收。  
- 阿凯看着窗外变暗的海，几乎要笑：岛自己把门锁上了。

**白天困雨**

- 三人被关在屋里打牌、煮面、听雨。晓晓兴致高。珊珊走路滞涩，晓晓以为是晒伤。  
- 牌桌下：他的赤脚伸进她两腿之间，脚趾隔着短裤磨。晓晓盯着牌，还帮珊珊出主意。她必须盯着牌面，不能低头。

**夜间：漏雨借口**

- 阁楼天窗起雾、滴水。晓晓让阿凯上去看看，自己在客厅追剧。  
- 木梯、雨声、电视剧笑声。尺度：她醒着被再次进入，内射。她求外射、求怕怀孕。他偏内射。  
- 中途晓晓在楼下喊：「修好没有？要不要水桶？」珊珊体内夹着他，必须自己开口回：「……还好，小漏！」声音要正常。  
- 这是本章最脏的一笔：她第一次为了掩护奸淫而主动对闺蜜撒谎。

**本章功能**：替代地铺章。威胁源不是「五十厘米外的呼吸」，是「楼下随时会喊，而你必须替他回答」。

---

### 第六章｜停电台（第五日夜·台风）

**空间再改写**

- 风力加大，面海落地窗被预警可能破裂。晓晓恐玻璃，坚持钻进一楼无窗杂物间（放拖把、纸箱、备用被），觉得那里最安全。  
- 她让「阿凯和珊珊守客厅」：客厅有沙发，也方便听天气预报。她隔一扇薄木门，十米远。  
- 这是全新的三人几何：不是同床，不是地铺，是「妻子把自己锁进安全屋，把丈夫和闺蜜留在风暴正中央」。

**停电**

- 灯灭。只剩蜡烛和天树的闪电。潮声像砸墙。  
- 尺度拉满，但动作设计全部服务新场景：  
  1. 先让珊珊穿上晓晓那件没来得及穿的纪念日睡裙（晓晓怕冷，把它留在沙发上）。  
  2. 在落地窗前从后面进入——窗外是黑海和被风抽直的雨。每道闪电都可能照出两具交叠的影子；杂物间门缝里，晓晓还在问「你们怕不怕」。  
  3. 他让珊珊回答。她必须边被干边说「不怕，你睡吧」。  
  4. 他要她看着海高潮。不是为了新的器官，是为了她第一次在清醒里被身体背叛——恨自己的生理反应，胜过恨他。  
  5. 内射之后仍不拔，等下一声雷，再补一次口，射在睡裙胸口。这件裙子晓晓明天还想穿上船。

**章末**

- 晓晓从杂物间探头：「客厅好安静，你们没睡着吗？」  
- 阿凯用被子盖住珊珊赤裸的下半身和那件脏掉的裙子：「看雨呢。睡吧。」  
- 门重新关上。珊珊在闪电里睁着眼，海在外面，精在里面。

**本章功能**：替代 KTV 厕所。封闭、喧嚣、近在咫尺的闺蜜，全部换成台风和一扇杂物间的门。最后一夜的完成式是「穿妻子的衣服、对妻子说话、被妻子的丈夫灌满」。

---

### 第七章｜回航（第六日晨，仍算五日行程的尾声）

**清晨**

- 风停。开航通知来了。晓晓收拾纪念品，哼歌。  
- 最后一次发生在户外花洒间——晓晓在屋里塞行李箱，喊「充电宝找到没有」。花洒间门帘不隔音，只隔视线。他短、狠、不求再开发新部位，只要她夹着走去码头。  
- 她在水声里扇他一耳光。打完仍然压着声音。胜利的最终形态与原作同构，但耳光打在盐和湿沙子上，不是一室一厅的玄关。

**渡轮**

- 回程甲板。晓晓靠着他睡觉。珊珊独自抓栏杆，看青屿缩小。  
- 他走过她身边，只留一句，口型或极低的声音：「照片留着。想安静，就当这五日是台风。」  
- 她问：「会删吗？」  
- 「不会。」

**收束意象**

- 原作收束在上海夜色和一室一厅。新作收束在船尾的浪。  
- 岛可以离开。盐会从皮肤上洗掉。把柄和体内的脏洗不掉。  
- 最后一句落到海上，不落到床上：她来找清静，他给她一座永远涨潮的岛。

## 七、人物心理（五日）

**谢珊珊**

- 第一日：把不安解释成「自己想多了」  
- 第二日：问了一句，发现问比不问更危险  
- 第三日：开始自己藏赃  
- 第四日：怕的不是痛，是晓晓会把她看成第三者  
- 第五日：为了掩护而主动撒谎；身体在风暴里背叛她  
- 回航：恨他，打他，仍替他保密

**晓晓**

- 全程善良、兴奋、爱拍照、爱过纪念日  
- 每一个「缺席」都出自爱：拍照、喝酒、祈福、怕玻璃伤到别人  
- 她越体贴，阿凯越好下手。这个结构不变，具体行为全换

**阿凯**

- 仍是会计算的人。新计算题是船班、潮汐、备用钥匙、天气预报、哪些照片「看起来像自愿」  
- 他的快感仍来自「近」：不是把晓晓支开越远越好，而是让晓晓始终隔一面墙、一道门、一声喊
